# 게임 진행 흐름 v0.1

> 작성일 2026-10-15 · 근거: [02-game-concept.md](02-game-concept.md)
> 이 문서는 "플레이어가 실제로 무엇을 하는지"를 화면 순서대로 설명한다.

## 1. 한 문장 요약

> 폐허가 된 길드의 새 단장이 되어 **의뢰를 하나씩 해결**한다. 의뢰 하나는 **갈림길이 있는 지도**이고, 지도 위 칸을 밟을 때마다 **대화(주사위 판정)**나 **전투**가 1~3분짜리로 벌어진다. 의뢰를 끝내면 길드가 조금씩 복구되고 동료가 늘어난다.

## 2. 전체 구조

```
메인 스토리 = 챕터 3~4개 (각 1~2시간)
 └ 챕터 1개 = 큰 의뢰 1개 (예: 1장 "붉은 수염 도적단")
     └ 의뢰 지도 = 칸(노드) 10~15개, 중간에 갈림길
         └ 칸 1개 = 대화 / 전투 / 탐색 / 캠프 중 하나 (1~3분)
```

챕터와 챕터 사이에는 **길드 하우스**로 돌아온다.

## 3. 화면별 설명

### 3.1 길드 하우스 (허브)

- 화면에는 **길드 하우스 배경만** 나온다. 동료가 서 있지 않는다
- 배경은 길드 복구 단계에 따라 바뀐다: 폐허 → 복구 1단계 → 복구 2단계. **배경이 바뀌는 것 자체가 진행 보상**이다
- 메뉴:

| 메뉴 | 하는 일 |
|---|---|
| 의뢰 게시판 | 다음 메인 의뢰, 동료 개인 의뢰, 지난 의뢰 다시 하기 |
| 동료 | 파티 편성(4명), 장비, 레벨, 스킬 확인 |
| 대화 | 동료를 골라 일상 대화, 호감도 이벤트 (일상복 스탠딩) |
| 상점 | 동료 팩, 확장팩, 주사위 스킨 |
| 기록 | 엔딩 도감, CG 갤러리, 지난 선택 기록 |

### 3.2 의뢰 지도

- 양피지 지도 위에 칸들이 길로 이어져 있다. 갈림길에서 어느 쪽으로 갈지 고른다
- 칸 종류:

| 칸 | 내용 | 시간 |
|---|---|---|
| 💬 대화 | NPC나 사건을 만난다. 선택지와 주사위 판정 | 1~2분 |
| ⚔️ 전투 | 7×5 칸 택티컬 전투 | 2~3분 |
| 🔍 탐색 | 상자, 함정, 수상한 흔적. 짧은 판정 하나 | 30초 |
| 🔥 캠프 | 체력 회복, 동료 대화, 호감도 이벤트 | 1~2분 |
| 💀 보스 | 챕터 마지막 전투 | 3~5분 |

- **앞 칸의 결과가 뒤 칸을 바꾼다.** 대화에서 정보를 얻으면 숨은 길이 열리고, 판정에 실패하면 적이 대비하고 있다

### 3.3 대화 (주사위 판정)

- 배경 위에 말하는 캐릭터의 스탠딩이 서고, 아래 대사창에 대사와 선택지가 나온다
- 선택지 중 일부는 **판정 선택지**다: `[설득] 정보를 캐낸다 (성공률 65%)`
- 파티에 특기를 가진 동료가 있으면 전용 선택지가 생긴다: `[위협 · 리나] 검을 뽑아 든다 (75%)`
- 고르면 화면에 d20 주사위가 굴러가고 결과가 나온다. **실패해도 이야기는 계속되고, 다른 전개가 된다**
- 실패하면 "영감" 토큰을 얻고, 나중에 판정을 다시 굴릴 때 쓴다

### 3.4 전투

- 7×5 칸 맵에 아군 4명과 적 3~6명이 선다
- **내 턴:** 아군 4명을 원하는 순서로, 한 명씩 "이동 1번 + 행동 1번"을 한다 → **적 턴:** 적이 전부 움직인다
- 공격하기 전에 명중률이 %로 보인다. 굴림은 d20이다
- 환경을 쓴다: 기름 지대에 불 붙이기, 물웅덩이에 전기, 절벽으로 밀어 떨어뜨리기, 높은 곳에서 쏘기
- 3~5라운드, 2~3분 안에 끝난다. 이기면 경험치와 전리품을 얻는다

### 3.5 캠프

- 의뢰 지도 중간의 휴식 칸이다
- 체력 회복, 그리고 동료 한 명을 골라 대화한다(일상복 스탠딩). 대답에 따라 호감도가 오른다

## 4. 예시: 1장 첫 30분

| 순서 | 화면 | 일어나는 일 |
|---|---|---|
| 1 | CG | 폐허가 된 길드 하우스. 리나가 녹슨 열쇠를 내밀며 말한다. "오늘부터 당신이 단장입니다." |
| 2 | 길드 하우스 | 폐허 배경. 의뢰 게시판에 마을 사람의 의뢰가 붙어 있다. "도적이 마을을 털어 갑니다" |
| 3 | 의뢰 지도 | 출발. 첫 갈림길: **숲길** 또는 **마을 외곽** |
| 4 | 💬 대화 | 숲길에서 수상한 덫사냥꾼을 만난다. 선택지: `[설득] 정보를 묻는다 (60%)` / `[위협 · 리나] (75%)` / 그냥 지나간다 |
| 5a | 성공하면 | 도적 은신처의 뒷길을 알아낸다 → 보스전에서 **기습 선공** |
| 5b | 실패하면 | 사냥꾼이 도망쳐 도적에게 알린다 → 다음 전투에 **적이 2명 더** 나온다. 영감 토큰 +1 |
| 6 | ⚔️ 전투 | 늑대 3마리와 도적 2명. 리나가 방패로 버티고, 아델하이트가 기름 건초에 불을 붙여 늑대를 몰아넣는다. 3라운드에 끝 |
| 7 | 🔥 캠프 | 리나가 요리를 하겠다고 나서다가 냄비를 태운다(일상복 스탠딩). 위로해 주면 리나의 호감도가 오른다 |
| 8 | 💀 보스 | 도적 두목 "붉은 수염". 4번에서 성공했다면 우리 편이 먼저 움직인다 |
| 9 | 💬 선택 | 쓰러진 붉은 수염을 어떻게 할까? **영주에게 넘긴다 / 그 자리에서 처단 / 놓아준다.** 정답이 없는 BG3식 선택이고, 2장에서 영주와 마을의 반응이 달라진다 |
| 10 | 길드 하우스 | 보상으로 길드 복구 1단계 → 배경이 바뀐다. 도적단에서 빠져나온 소매치기 **세실**이 합류한다. 2장 의뢰가 열린다 |

## 5. 성장과 수집

| 요소 | 어떻게 늘어나나 | 무엇을 주나 |
|---|---|---|
| 동료 레벨 | 전투 경험치 | 능력치, 스킬 강화 |
| 장비 | 전리품, 상점 | 전투력, 판정 보너스 |
| **길드 복구** | 메인 의뢰 완료 | 허브 배경 변화, 캠프 회복량 증가, 새 메뉴 해금 |
| **호감도** | 캠프·길드 대화, 선택지 | 개인 의뢰 해금 → 끝까지 오르면 **호감도 CG + 개인 엔딩** |
| 엔딩 도감 | 다른 선택, 다른 동료로 의뢰 다시 하기 | 수집 요소, 숨은 대사 |

## 6. 연애 요소: 암시 정도

- 주인공(단장)은 화면에 나오지 않는다. 동료와의 관계는 **호감도**로 표현한다
- 호감도 이벤트는 신뢰와 우정에서 시작해, 높은 단계에서 **연애 감정을 암시**한다(설레는 대사, 단둘이 있는 장면)
- 호감도 최대 이벤트에서 **호감도 CG** 한 장과 개인 엔딩이 나온다. 연애를 확정하거나 노골적으로 묘사하지 않는다
- 동료 사이에도 질투나 놀림 같은 반응을 넣어 서브컬처다운 재미를 준다

## 7. 플레이 분량

| 항목 | 시간 |
|---|---|
| 메인 스토리 (무료) | 챕터 3~4개 × 1~2시간 = **4~8시간** |
| 동료 개인 의뢰 | 동료당 30분~1시간 |
| 다른 루트로 다시 하기 | 챕터당 30분~1시간 (선택과 동료를 바꿔서) |
| 유료 동료 팩 | 동료 1명 + 개인 의뢰 1~2시간 |
| 유료 확장팩 | 새 지역 챕터 2~3개 |
