# 게임 진행 흐름 v0.2

> 작성일 2026-10-15 · 근거: [02-game-concept.md](02-game-concept.md), [05-combat.md](05-combat.md)
> 이 문서는 "플레이어가 실제로 무엇을 하는지"를 화면 순서대로 설명한다.
> **v0.2 변경:** 흔한 "의뢰 게시판 → 갈림길 지도" 구조를 두 가지로 바꿨다.
> ① **다 못 하는 의뢰** — 매주 의뢰가 여러 개 오지만 일부만 할 수 있고, 안 간 의뢰는 결과가 남는다
> ② **써 내려가는 연대기** — 의뢰 지도가 필사본 페이지이고, 판정과 선택의 결과로 길이 잉크처럼 그려진다
> ③ **봉인된 방과 과거 회상** — 길드를 복구하면 잠긴 방이 열리고, 몰락 당시의 사건을 과거 길드원으로 직접 플레이한다
> ④ **행운 주사위** — 의뢰를 출발할 때 d20 2개를 미리 굴려 들고 다니며, 높은 눈은 우리 판정에, 낮은 눈은 적에게 배치한다
> ⑤ **짧은 이야기 장면 (니케식)** — 이야기는 의뢰에 들어갈 때와 끝날 때 짧은 장면으로만 나온다. 긴 대화는 없다 (3.7절)

## 1. 한 문장 요약

> 폐허가 된 길드의 새 단장이 되어, **매주 밀려드는 의뢰 중 몇 개만 골라** 해결한다. 의뢰는 **필사본 한 페이지**에 판정과 선택의 결과가 써 내려가지며 진행되고, 고르지 않은 의뢰는 세상에 흔적을 남긴다.

## 2. 전체 구조

```
메인 스토리 = 챕터 3~4개
 └ 챕터 1개 = 3주
     └ 한 주 = 의뢰 3~4개가 들어오고, 그중 2개를 고른다
         └ 의뢰 1개 = 연대기 한 페이지 (칸 4~8개, 10~20분)
             └ 칸 1개 = 대화 / 전투 / 탐색 / 캠프 (1~3분)
 └ 챕터 마지막 주 = 반드시 해야 하는 **결전 의뢰** (보스, 칸 10~12개)
```

- 한 챕터에서 실제로 하는 의뢰는 **일반 의뢰 4~5개 + 결전 의뢰 1개**다
- 들어오는 의뢰는 챕터당 8~10개라서, **한 번 플레이로는 절반 정도만 보게 된다** → 다시 할 이유가 된다

## 3. 화면별 설명

### 3.1 하웰 마을 (허브) (2026-10-17 사용자 요청으로 바꿈)

- 메인 화면은 **하웰 마을 전경** 일러스트다. 건물을 누르면 그 장소로 들어간다. 건물 위에는 양피지 이름표가 붙고, 새 일(서브 스토리, 새 물건, 소문)이 있으면 붉은 인장이 뜬다 (코드로 그림)
- 주말 정산 뒤에는 같은 전경을 저녁 색조로 바꿔 보여 준다 (셰이더, 새 그림 없음)
- 길드가 크면 마을도 북적인다: 전경 2단계(한산함 → 북적임)는 P2에서 그린다

| 장소 | 들어가면 (배경) | 하는 일 |
|---|---|---|
| **길드 하우스** | 길드 홀 (폐허 → 공사 1~5단계마다 바뀜). 로비에는 **부관 노라**(N14)가 서서 이번 주 할 일을 한마디로 알려 준다. 동료가 로비를 차지하지 않게 해 어느 동료도 더 자주 보이지 않는다 (2026-10-17) | **의뢰 게시판**(이번 주 의뢰 고르기 3.2절, 위탁 의뢰), 동료(편성 3명·장비·레벨·스킬), 서브 스토리 알림, **길드 운영**(재건 공사·시설·스카우트실·모험가 명부·장부, 3.8절) |
| **선술집 「구리 국자」** | 선술집 (마르타) | **소문 듣기**(다음 주 의뢰 힌트, 적 정보 한 줄), 식재료 납품(마르타 호감도, 6.4절), 일부 동료의 **영입 면접** 장소 |
| **대장간** | 대장간 (대장장이) | 장비 사기·팔기, **장비 강화**(금화 + 재료). 강화 상한은 길드 무기고 레벨을 따른다 |
| **잡화점** | 잡화점 (잡화점 주인) | 소모품(회복약 등), **선물**, 식재료 |
| **촌장 집** | 촌장 집 (촌장) | 메인 스토리 장면, **길드 등급 승급** 장면, 가끔 마을 부탁(작은 의뢰 1개) |
| 마을 광장 | 마을 광장 (우물) | **주말 소식**이 붙는 곳. 마을 사람 한마디가 지난주 결과를 반영한다 |

- **연대기**(완성한 페이지 책, CG 갤러리, 음악 감상)와 설정은 화면 구석 메뉴로 언제든 연다
- 확장팩은 스토어(DLC)에서 산다. 게임 안 상점에는 돈 주고 사는 물건이 없다. 주사위 스킨은 플레이 보상

### 3.2 이번 주 의뢰: 다 못 한다

- 지역 지도(일러스트) 위에 이번 주에 들어온 의뢰 3~4개가 핀으로 꽂혀 있다
- **이번 주에 할 수 있는 의뢰는 2개.** 나머지는 포기해야 한다

| 의뢰 종류 | 설명 | 예 |
|---|---|---|
| 마을·세력 의뢰 | 지역 사람들의 부탁 | "북쪽 마을에 도적이", "영주의 세금 징수 호위" |
| 동료 개인 의뢰 | 호감도가 일정 이상이면 들어온다 | "세실: 옛 동료를 구해 줘" |
| 긴급 의뢰 | 이번 주에만 유효 | "수도원에 역병 환자가" |
| **결전 의뢰** | 챕터 마지막 주에 반드시 등장. 피할 수 없다 | "붉은 수염의 본거지" |

**안 간 의뢰의 결과**
- 고르지 않은 의뢰는 그냥 사라지지 않는다. **다음 주 소식**으로 결과가 들려온다
  - "북쪽 마을이 도적에게 털렸다" → 그 마을 상점이 닫히고, 마을 사람 NPC가 원망한다
  - "세실의 옛 동료가 교수형을 당했다" → 세실의 호감도가 떨어지고 개인 의뢰 줄거리가 바뀐다
  - "영주의 세금 징수가 폭동으로 끝났다" → 영주와의 관계가 나빠진다
- **앞 주의 선택이 결전 의뢰를 바꾼다**
  - 도적 보급로를 끊는 의뢰를 했다면 → 결전에서 보스 증원이 없다
  - 북쪽 마을을 구했다면 → 결전에 마을 자경단이 원군으로 온다
- 정답은 없다. **무엇을 포기할지 고르는 것**이 이 게임의 BG3식 선택이다
- 의뢰 핀에는 의뢰인 세력(왕관, 교회, 상회, 회색 쥐)의 인장이 찍혀 있다. 이야기 속 표시일 뿐 우호도 시스템은 없다 (v0.5, 02-game-concept.md 0.1절). 고르지 않은 의뢰는 주말 소식 한 줄과 결전 수치에만 반영한다

### 3.3 의뢰 진행: 써 내려가는 연대기

의뢰를 시작하면 **빈 필사본 페이지**가 펼쳐진다.

```
┌─────────────────────────────────────────┐
│  ❦ 하웰 모험가 길드 연대기 · 제3주          │
│                                           │
│  [출발] ──── [💬 수상한 사냥꾼]             │
│                    ╲                      │
│                     ╲ (설득 성공으로 써짐)  │
│                      [🔍 숨은 뒷길] ── ?   │
│                                           │
│        ? (아직 쓰이지 않은 여백)           │
│                                           │
│  "단장은 덫사냥꾼을 말로 구슬려           │
│   도적 소굴의 뒷길을 알아냈다."            │
│                              🐌⚔️ (여백 낙서)│
└─────────────────────────────────────────┘
```

- **처음에는 출발 칸과 첫 칸만 보인다.** 앞길은 비어 있는 양피지다
- 칸을 끝낼 때마다 결과가 **한 줄의 연대기 문장**으로 적히고, 다음 칸들이 **잉크로 그려지며 나타난다**
- **판정 결과에 따라 써지는 길이 달라진다**
  - 설득 성공 → 숨은 뒷길이 써진다
  - 설득 실패 → 도망친 사냥꾼을 쫓는 길이 써진다(다른 전개, 막히지 않음)
- 갈림길이 써지면 그때 어느 쪽으로 갈지 고른다. 갈림길은 **같은 페이지 안에서 다시 합쳐진다** (페이지 밖으로 이야기가 갈라지지 않는다)
- **여백 낙서:** 중세 필사본의 엉뚱한 여백 그림(달팽이와 싸우는 기사 같은)처럼, 의뢰에서 일어난 일에 맞는 작은 낙서가 여백에 그려진다. 늑대와 싸웠으면 늑대 낙서, 리나가 냄비를 태웠으면 탄 냄비 낙서. **서브컬처식 밈과 웃음 포인트**
- 칸 종류는 그대로다: 💬 대화 / ⚔️ 전투 / 🔍 탐색 / 🔥 캠프 / 💀 보스

### 3.3.1 행운 주사위

- 페이지를 펼칠 때 **d20 2개를 굴려** 페이지 위쪽 트레이에 놓는다. 예: `[18] [3]`
- 이 페이지에서 일어나는 모든 판정(대화, 전투)에 굴리는 대신 들고 있는 눈을 놓을 수 있다
  - **높은 눈** → 꼭 성공해야 하는 우리 판정에 (설득, 결정타)
  - **낮은 눈** → 적에게 "운명 낙인"을 찍어 그 적의 다음 굴림을 망친다 (보스의 큰 공격 막기)
- 캠프 칸에서 1개 더 굴린다. 우리 굴림에서 자연 1이 나와도 1개 더 얻는다 (**최대 3개**, 넘치면 하나를 골라 버린다)
- 페이지가 끝나면 남은 주사위는 사라진다 → **이 페이지 안에서 언제 쓸지**가 고민이 된다
- 연대기 문장에도 남는다: "단장은 운명을 붙잡아 18을 놓았고, 사냥꾼은 끝내 입을 열었다"

### 3.4 연대기 완성과 공유

- 의뢰를 끝내면 페이지가 **완성된다:** 첫 글자 장식, 금박 테두리, 길드 인장이 찍힌다
- 완성된 페이지는 **사람마다 다르다** (어떤 판정이 성공했는지, 누구를 데려갔는지, 무엇을 골랐는지)
- **이미지로 저장·공유**할 수 있다 → 플레이어가 자기 연대기를 SNS에 올리는 것이 자연스러운 홍보가 된다
- 메뉴의 "연대기"에 모든 페이지가 책으로 쌓인다. 엔딩에서 이 책 전체가 **"당신이 쓴 길드의 역사"**로 마무리된다

### 3.5 봉인된 방과 과거 회상

> ⚠️ **다시 정해야 함 (2026-10-17 사용자: 하웰 모험가 길드는 전대 용사와 관계없는 평범한 길드다).** 아래는 '용사의 길드' 시절 설계라 그대로 쓸 수 없다. 회상 파티(에드릭·알도·젊은 고드릭)로 직접 플레이하는 재미는 살리고, 회상이 열리는 계기를 바꾼다. 가안: 고드릭이 털어놓는 기억, 의뢰 중에 찾는 에드릭의 여행 일지 조각. 길드 방 복구는 시설 업그레이드로만 쓴다.

길드 복구는 숫자 게이지가 아니라 **잠긴 방을 여는 일**이다. 방마다 몰락 당시의 기억이 남아 있고, 그 기억을 **과거 길드원으로 직접 플레이**한다.

**전대 용사 일행 (회상 파티 3명, 교체 불가)**

| 인물 | 역할 | 현재와의 연결 |
|---|---|---|
| 에드릭 | 용사, 지휘관형 | 용사 일행 해산의 중심. 현재는 행방불명 |
| 기사 알도 | 탱커 | **리나의 아버지.** 몰락 때 죽었다고 알려져 있다 |
| 젊은 고드릭 | 석궁수 | 현재의 고드릭. 그가 말하지 않는 진실을 플레이어가 먼저 보게 된다 |
| 모르칸트 | (회상 속 NPC) 용사 일행의 검사 | **훗날의 흑기사(3장 보스).** 회상마다 조금씩 변해 간다 |

**방과 회상 순서**

| 여는 시점 | 방 | 회상 내용 |
|---|---|---|
| 1장 결전 후 | 기록실 | 전성기의 길드. 에드릭 일행의 평범한 의뢰 하나. 모르칸트와의 우정 |
| 2장 결전 후 | 무기고 | 수도원 사건. 에드릭과 모르칸트가 처음으로 충돌한다 |
| 3장 결전 후 | 길드장 집무실 | 몰락의 밤. 누가 무엇을 했는지가 드러난다 |
| 최종장 직전 | 지하 금고 | 에드릭이 남긴 마지막 기록. 최종장의 열쇠 |

**회상의 규칙**
- 회상도 연대기 한 페이지(칸 4~6개)로 진행된다. 다만 **바랜 세피아 잉크**로 그려지고, 과거 길드원이 직접 쓴 문장으로 적힌다
- **과거의 큰 사건은 바꿀 수 없다.** 대신 회상 속 판정과 선택이 **어떤 진실 조각을 알아내는지**를 정한다
  - 예: 몰락의 밤에 고드릭으로 `[조사] 모르칸트의 방을 뒤진다`에 성공하면 → 최종장에서 흑기사를 설득하는 선택지가 열린다
- 회상에서 본 것은 **현재의 동료 대화를 바꾼다.** 알도의 마지막을 본 뒤에는 리나와의 대화에 새 선택지가 생긴다
- 회상 전투는 과거 파티 3명으로 고정이다. 현재 동료와 다른 스킬 구성이라 새로운 전투 퍼즐이 된다

### 3.6 대화, 전투, 캠프

- **💬 판정 칸:** 상황 1~3줄 → 주사위 판정 선택지 → 결과 1~2줄. 파티 3명의 특기에 따라 선택지가 달라진다. 이야기를 길게 풀지 않고 **선택만 남긴다**
- **전투:** 칸 택티컬 전투 (맵마다 5×4 ~ 9×6), 3명 파티 ([05-combat.md](05-combat.md))
- **캠프:** 체력 회복, **파티 교체**, **행운 주사위 1개 굴리기** (미리엄이 파티에 있으면 2개). 호감도 이벤트가 있으면 짧은 장면 하나 (건너뛰어도 된다)

### 3.7 이야기 장면: 짧게, 니케처럼

이야기는 **정해진 자리에서만, 짧게** 나온다. 니케처럼 의뢰에 들어갈 때 짧은 장면을 보고 바로 플레이로 넘어간다.

**나오는 자리와 길이**

| 자리 | 길이 (대사 줄 수) | 내용 |
|---|---|---|
| 의뢰 시작 장면 | **8줄 이하** (약 30초) | 의뢰인 또는 동료가 상황을 말한다. 끝에 "출발" |
| 의뢰 마무리 장면 | **5줄 이하** | 결과에 대한 동료 반응 한두 마디. 판정 결과에 따라 대사가 바뀐다 |
| 챕터 시작 / 결전 전후 | **15줄 이하** | 챕터의 큰 사건. CG가 있으면 여기서 쓴다 |
| 호감도 이벤트 | **6줄 이하** | 동료 한 명과 일상복으로. 마지막에 선택지 1개 |
| 💬 판정 칸 | 상황 3줄 + 결과 2줄 | 3.6절 |

**쓰는 규칙**
- 대사 한 줄은 **대사창 두 줄 이내** (한국어 약 40자, 일본어 약 45자, 영어 약 90자)
- 한 사람이 **3줄 넘게 연달아 말하지 않는다.** 설명은 대사보다 연대기 문장으로 넘긴다
- 세계관 설명은 장면에 넣지 않는다. 알고 싶은 사람만 **연대기 책의 주석**(코드로 그린 여백 메모)에서 읽는다
- 장면 하나에 스탠딩은 **최대 2명**

**화면 (니케식)**
- 배경 + 스탠딩 1~2명 + 아래쪽 대사창(이름표). 말하는 사람은 밝게, 듣는 사람은 살짝 어둡게
- 오른쪽 위에 **자동 / 건너뛰기 / 기록** 버튼이 항상 있다
- **건너뛰기를 누르면 요약 한 줄**이 연대기 문장으로 뜬다 → 건너뛰어도 흐름을 놓치지 않는다
- 이미 본 장면은 다시 할 때 자동으로 빠르게 넘어간다

**분량 계산:** 의뢰 하나에 이야기 장면은 시작과 마무리를 합쳐 **1분 안팎**. 나머지 시간은 판정, 전투, 선택이다

### 3.8 길드 운영 (2026-10-17 사용자 요청)

> 몰락한 길드를 다시 세우는 맛을 숫자로도 느끼게 한다. 원칙은 **단순하게, 일주일에 한 번 정리, 파산·게임 오버 없음.** 단장의 재능(사람을 쓰는 눈)이 곧 이 화면들이다 (02-game-concept.md 8.0절).

**한 주의 흐름**

```
주초: 하웰 마을에서 준비 — 재건 공사, 시설, 장비 강화, 모험가 스카우트, 위탁 의뢰 맡기기, 선술집 소문
 → 의뢰 게시판에서 이번 주 의뢰 2개 고르기 → 의뢰 플레이 (연대기 페이지)
 → 주말: 단장의 장부(정산) + 마을 광장 소식 → 다음 주
```

**자원은 셋만 쓴다**

| 자원 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 금화 | 의뢰 보상, 위탁 의뢰, 장비 팔기 | **재건 공사(가장 큰 지출)**, 시설, 장비, 모험가 계약금, 소모품, 선물, 상회 빚 |
| 재료 (목재·철·약초 3종) | 의뢰 전리품, 위탁 의뢰 | 재건 공사, 시설, 장비 강화 |
| **명성** | 의뢰 완료, 결전, 마을 부탁, 판정 대성공, 위탁 의뢰(조금) | 길드 등급 승급 (쓰면 줄지 않고 쌓인다) |

**① 길드 등급 (명성)**
- 등급: **동패 → 은패 → 금패** (1~3장 범위. 그 위는 확장 때 정한다). 길드 간판에 등급 패가 걸린다
- 명성이 문턱을 넘으면 촌장 집에서 짧은 승급 장면. 승급하면 더 크고 보상 좋은 의뢰가 게시판에 붙고, 새 동료가 찾아오고, **세력이 길드를 주목하기 시작한다** (빠르게 크는 길드, 06-factions.md)
- 기준: 의뢰를 고르게 해 나가면 1장 결전 무렵 은패, 3장 결전 무렵 금패. 아무리 서툴러도 장이 끝날 때는 다음 등급에 닿게 맞춘다 (진행 막힘 없음)

**② 재건 공사 (돈을 많이 모아야 다시 세운다) (2026-10-17 사용자)**
- 길드 하우스를 다시 세우는 것이 **금화의 가장 큰 목표**다. 공사는 단계마다 큰 금액 + 재료가 든다
- 공사는 **5단계** (2026-10-17 사용자). 단계가 끝날 때마다 길드 하우스 배경이 바뀌고, **지을 수 있는 시설 칸과 시설 최고 레벨이 늘어난다**

| 공사 | 필요 (가안, 밸런스 때 조정) | 열리는 것 | 목표 시점 |
|---|---|---|---|
| 0. 폐허 (시작) | — | 시설 2칸 (게시판, 스카우트실), 최고 1레벨, 스카우트실 1 | 1장 시작 |
| 1. 지붕 수리 | 금화 350 · 목재 5 | 시설 3칸, 스카우트실 2 | 1장 중반 |
| 2. 큰 홀 복구 | 금화 700 · 목재 6 · 철 2 | 시설 4칸, 최고 2레벨, 스카우트실 3 | 1장 결전 전후 |
| 3. 2층 복구 | 금화 1,100 · 목재 8 · 철 4 | 시설 5칸 | 2장 |
| 4. 별채 증축 | 금화 1,500 · 목재 10 · 철 6 | 시설 6칸, 최고 3레벨, 스카우트실 4 | 3장 |
| 5. 길드 완공 | 금화 2,000 · 목재 12 · 철 8 · 약초 4 | 시설 7칸, 스카우트실 5 | 3장 끝 무렵. 위탁 의뢰 약 10주치 + 메인 스토리 전부로 완공 가능하게 맞춘다 (2026-10-17 사용자) |

- 길드 하우스 배경은 단계마다 1장씩 (폐허 + 공사 5장 = 6장). 같은 구도로 그려 단계가 바뀔 때 비교가 되게 한다

- 금화는 의뢰 보상만으로는 빠듯하고, **위탁 의뢰(⑤)를 꾸준히 돌려야** 공사가 제때 끝난다. "사람을 잘 쓰는 단장"이 돈도 잘 번다
- 공사가 늦어도 이야기는 막히지 않는다 (배경과 시설만 늦게 열린다)

**③ 시설 (길드 하우스의 방)**
- 금화 + 재료로 짓고 올린다. 지을 수 있는 칸 수와 최고 레벨은 재건 공사 단계를 따른다

| 시설 | 효과 (1 / 2 / 3레벨) | 단장의 무기 |
|---|---|---|
| **스카우트실** | 매주 찾아오는 모험가 지원자 수와 최고 등급이 오른다 (④ 표) | 사람 |
| **훈련장** | 파티에 못 간 동료도 경험치를 받는다 (30% / 50% / 70%) | 육성 |
| **무기고** | 대장간 강화 상한 +1단계씩 (무기고 없이 +1, 3레벨이면 +4) | 장비 |
| **기록실** | 1: 위탁 의뢰 성공률이 숫자로 / 2: 의뢰 지도에 메인 의뢰 적 구성 / 3: 적 체력·공격력까지 | 전략 (서기 습관) |
| **숙소** | 동료 정원 4 → 6 → 8명, 모험가 명부 인원 6 → 10 → 14명 | 사람 |
| **주방** | 1: 야영 칸 행운 주사위 +1 / 2: 의뢰를 떠날 때 식재료 1개로 도시락 → 그 의뢰 전투에서 동료 체력 +4 / 3: 도시락 체력 +8 | 유대 |
| **의뢰 게시판** | 3레벨에서 주당 고를 수 있는 의뢰 +1 (3장 이후) | 관리 |

**④ 모험가 인력풀 (명부) (2026-10-17 사용자)**
- 동료(이야기와 일러스트가 있는 주인공들)와 별개로, 길드에 등록한 **일반 모험가**들이다. 등급은 **S · A · B · C · D · F**
- **일러스트는 없다.** 모험가는 Claude가 SVG로 그린 **카드**로만 나온다: 등급별 테두리 색, 직업 문장(전사·궁수·마법사·도적·수호자·사제·견습), 이름, 실력, 특기 태그, 특성 한 줄, 보수 몫. 견본 `art/src/ui/cards/` (`tools/icons/adventurer_cards.py`)
- 모험가는 전투와 연대기 페이지에 나오지 않는다. **위탁 의뢰(⑤)에만** 쓴다
- 이름·직업·특성은 목록에서 조합해 만든다 (특성 30~40개: "겁쟁이", "손버릇", "백발백중" 등). 이야기 장면 없음

| 등급 | 실력 (대략) | 계약금 | 보수 몫 |
|---|---|---|---|
| F | 10~20 | 아주 쌈 | 10% |
| D | 25~35 | 쌈 | 15% |
| C | 40~50 | 보통 | 20% |
| B | 55~65 | 비쌈 | 25% |
| A | 70~80 | 아주 비쌈 | 30% |
| S | 85~95 | 큰돈 | 35% |

- 계약금은 처음 한 번, 주급은 없다. 대신 위탁 의뢰 보상에서 **보수 몫**만큼 떼어 간다
- 위탁 의뢰를 3번 성공하면 **승급 시험**(다음 주 위탁 의뢰 하나가 시험이 된다). 붙으면 한 등급 오른다. 최고 A까지, **S는 스카우트로만** 온다

**스카우트 (스카우트실 업그레이드)**
- 매주 초 스카우트실에 **지원자 카드**가 몇 장 붙는다. 마음에 드는 모험가를 계약금을 내고 명부에 올린다. 안 뽑은 지원자는 그 주가 지나면 떠난다
- 스카우트실을 올려야 더 많이, 더 높은 등급이 찾아온다

| 스카우트실 | 주마다 지원자 | 나올 수 있는 최고 등급 |
|---|---|---|
| 1 | 2명 | D |
| 2 | 3명 | C |
| 3 | 3명 | B |
| 4 | 4명 | A |
| 5 | 4명 | S (드물게) |

- 스카우트실 4·5레벨은 재건 공사 4·5단계 뒤에 열린다 (1~3장 범위에서는 A까지가 목표, S는 운 좋으면 한 명)
- 길드 등급(①)이 오르면 지원자 등급이 조금 높게 나온다

**⑤ 위탁 의뢰 (서브)**
- 의뢰 게시판 아래 칸에 매주 **위탁 의뢰 3~5개**가 붙는다: 토벌, 호위, 정찰, 조사, 채집, 운반 같은 작은 일
- 명부의 모험가 1~3명을 골라 맡긴다. 화면에는 **필요 실력**과 맞는 특기, **성공률**이 바로 보인다 (기록실 레벨이 높을수록 정확하다)
- 결과는 **주말 장부에 한 줄**로만 나온다. 장면, 전투, 연대기 페이지 없음 (제작 비용 낮음)
- **보상은 메인 의뢰보다 적다** (같은 급 기준 약 50~60%, 거기서 보수 몫을 뗀다). 명성은 조금만 오른다
- 실패하면 보상이 없고, 맡은 모험가가 **다쳐서 한 주 쉰다.** 죽거나 사라지지 않는다 (가볍게)
- 동료가 이번 주 파티에 없으면 위탁 의뢰의 **대장**으로 붙일 수 있다: 성공률 +, 그 동료 호감도 +2. 벤치 동료도 놀지 않는다
- 메인 의뢰(동료와 직접 플레이) 2개 + 위탁 의뢰 여러 개를 동시에 굴리는 것이 "사람을 쓰는 단장"의 한 주다

**⑥ 단장의 장부 (주말 정산)**
- 주말마다 단장이 쓰는 **장부 한 페이지**(코드로 그린 필사본): 이번 주 수입(의뢰 보상, 위탁 의뢰), 지출(재건 공사, 시설, 장비, 계약금), 명성 변화, 위탁 의뢰 결과 한 줄씩, 다음 주 소식
- 동료·모험가 주급, 시설 유지비는 없다 (압박 대신 성장에 집중). 모험가는 위탁 보상에서 몫만 뗀다
- **상회 빚:** 금저울 상회가 길드 재건 자금 1,200을 빌려줬다. 장이 끝날 때까지 갚을 몫은 1장 300 · 2장 400 · 3장 500 (장부 화면과 결전 전 소식에서 갚는다). 못 갚으면 파산이 아니라, 상회가 다음 장에 **무보수 '추심 의뢰'** 하나를 게시판에 끼워 넣는다 (주당 의뢰 칸 하나를 차지). 다 갚으면 상회장의 짧은 장면

**만들 것:** 마을 전경 클릭 화면, 장소별 메뉴, 재건 공사·시설·스카우트·명부·위탁 의뢰·장부 화면(전부 코드 UI, 필사본 양식). **Claude SVG:** 모험가 카드, 직업 문장, 등급 인장, 시설 아이콘, 자원 아이콘. **Codex 일러스트:** 3.1절 표의 배경과 NPC(art/manifest.csv의 S33)뿐. 누가 무엇을 만드는지는 art/style-guide.md 8절 표를 따른다.

## 4. 예시: 1장 첫 주

| 순서 | 화면 | 일어나는 일 |
|---|---|---|
| 1 | CG | 폐허가 된 길드 하우스. 리나가 녹슨 열쇠를 내민다. "오늘부터 당신이 단장입니다." |
| 2 | 이번 주 의뢰 | 지도에 의뢰 3개: **A. 북쪽 마을의 도적** / **B. 숲의 덫사냥꾼 조사** / **C. 수도원 서고 정리(아델하이트 영입 기회)**. 2개만 할 수 있다 |
| 3 | 선택 | B와 C를 고른다 → A는 포기 |
| 4 | 연대기 (B) | 빈 페이지에 출발 칸. 행운 주사위 2개를 굴린다: `[17] [2]`. 첫 칸은 💬 수상한 덫사냥꾼 |
| 5 | 💬 대화 | `[설득] 정보를 묻는다 (60%)` / `[위협 · 리나] (75%)`. 위협에 **행운 주사위 17을 놓는다** → 확정 성공. "리나가 검을 뽑자 사냥꾼은 도적 소굴의 뒷길을 털어놓았다" 가 적히고 **🔍 숨은 뒷길** 칸이 써진다. 남은 주사위 `[2]` |
| 6 | ⚔️ 전투 | 뒷길에서 도적 보급대를 기습 (적 첫 턴 없음). 리나·세실·미리엄 3명. 도적 두목의 다음 공격에 **2를 낙인으로 찍어** 미리엄을 지킨다 |
| 7 | 완성 | 페이지에 인장. 여백에는 겁먹은 사냥꾼 낙서 |
| 8 | 연대기 (C) | 수도원 서고. 아델하이트와 만나 영입 |
| 9 | 다음 주 소식 | "북쪽 마을이 도적에게 털렸다." 마을 상점이 닫힌다. 대신 B에서 보급대를 쳤으므로 결전에서 보스 증원이 줄어든다 |
| 10 | … 3주차 | **결전 의뢰: 붉은 수염의 본거지.** 지금까지의 선택이 원군, 증원, 기습 여부를 바꾼다 |
| 11 | 길드 하우스 | 길드 복구 1단계 → 배경이 바뀌고 **기록실의 봉인이 풀린다** |
| 12 | 회상 | 세피아 잉크의 연대기 페이지. 젊은 에드릭, 알도, 고드릭으로 전성기의 의뢰를 플레이한다. 마지막 장면에서 모르칸트가 웃으며 길드 문장을 닦고 있다 |
| 13 | 현재 | 고드릭이 기록실 앞에서 말없이 서 있다. 리나: "…저 사람, 우리 아버지 맞죠?" → 2장으로 |

### 4.1 2장 중심 사건: 단장 납치 (가안, 2026-10-17 사용자 요청)

> 일행에서 가장 약한 사람은 단장이다 (02-game-concept.md 8.0절). 그 단장이 사라졌을 때 길드가 어떻게 움직이는지로 **그동안 쌓은 유대를 결산**한다. 플레이어는 "내가 없으면 이 아이들은?"을 직접 본다.

**언제:** 2장 중반(3~4주차). 이번 주 의뢰 고르기 대신 이 사건이 들어온다.

**누가, 왜:** 회색 쥐(세실의 옛 패거리)가 돈을 받고 납치를 실행하고, 뒤에서 **가면의 남자(N06)**가 의뢰했다. 노리는 것은 한 가지 질문: "에드릭은 왜 하필 너를 골랐지?" → 미스터리 ③(에드릭은 어린 나에게서 무엇을 봤나)이 여기서 본격적으로 시작된다.

**진행**

| 순서 | 화면 | 일어나는 일 |
|---|---|---|
| 1 | 이야기 장면 | 밤, 길드 홀. 단장이 혼자 장부를 정리하다 등 뒤에서 문이 열린다. 다음 날 아침, 동료들이 빈 책상과 바닥에 떨어진 펜을 발견한다 (짧게) |
| 2 | **갇힌 단장** (단장 혼자 쓰는 페이지) | 동료 보정 없이 **단장 자신의 능력치**로 판정 3~4번. 힘·민첩은 바닥이고 지능·매력·통찰만 쓸 만하다. 시간 끌기, 납치범에게서 정보 캐내기, 몰래 흔적 남기기(서기 습관: 벽의 표시, 찢은 장부 조각). 성공할수록 구출 페이지에 이점이 생긴다 (지름길, 기습, 적 수 감소) |
| 3 | **단장 없는 구출** (동료가 쓰는 연대기) | 페이지를 단장 대신 **호감도가 가장 높은 동료가 쓴다.** 글씨체와 문장이 그 동료답게 바뀐다(리나는 반듯하고 비장하게, 세실은 삐뚤빼뚤 반말로, 아델하이트는 짧고 냉소적으로). 단장의 지휘가 없으니 판정에 누가 나설지는 동료들이 스스로 정한다(자동). 2에서 남긴 흔적이 **"단장의 쪽지"** 칸으로 나타나 새 선택지를 연다 |
| 4 | 전투 | 회색 쥐 소굴. 세실이 옛 패거리 두목과 결판을 낸다 (세실 개인 이야기와 연결) |
| 5 | 재회 | 동료마다 반응이 호감도에 따라 다르다 (짧게). 호감도가 높은 동료는 화를 내거나 울고, 낮은 동료는 "…다음부턴 조심해" 정도 |
| 6 | 그 뒤 | 동료들이 단장 호위 순번을 정하는 소소한 일상 장면(힐링). 세실과 회색 쥐의 관계는 정해진 이야기로 정리한다 |

**단장 능력치 (가안):** 지능 +3, 매력 +2, 통찰 +2, 힘 −1, 민첩 −1, 건강 −1. 이 사건과 일부 특수 장면에서만 쓴다. 단장은 여전히 화면에 그리지 않는다 (페이지와 대사로만 존재).

**만들 것:** 연대기 페이지의 "동료 글씨체" 모드(글꼴·잉크색·문장 템플릿을 동료별로), 단장 단독 판정, "단장의 쪽지" 칸 종류. 새 아트: 회색 쥐 소굴 전투 배경, 회색 쥐 두목(N10) 스탠딩, 갇힌 방 배경.

## 6. 동료 유대: 서브 스토리 5단계와 호감도 (2026-10-17 사용자 결정)

> 동료는 모두 **서브 스토리 5단계**를 가진다. 호감도를 가장 많이 채우는 길은 **그 동료를 직접 데려가서 키우는 것**이고, 그다음이 **선물**이다. 서브 스토리는 놓치는 것 없이 모두 볼 수 있다 (v0.5: 분기 없음).

### 6.1 서브 스토리 5단계

| 단계 | 이름 | 여는 조건 | 형식 | 분량 | 보상 |
|---|---|---|---|---|---|
| 1 | 첫인상 | 합류 직후 | 길드 홀 짧은 장면 | 1분 | — |
| 2 | 속마음 | 호감도 20 | 장면 + 장면 안에서 끝나는 대답 고르기 | 2분 | 그 동료가 굴리는 판정 +1 |
| 3 | 개인 의뢰 | 호감도 45, 1장 완료 | **짧은 연대기 페이지 1장**(칸 3~4개, 전투 1번). 그 동료가 반드시 파티에 들어간다 | 10~15분 | 전용 장비 |
| 4 | 지난날 | 호감도 70, 2장 완료 | 장면 (일상복 스탠딩). 그 동료의 과거와 진짜 고민 | 2~3분 | 스킬 강화 1개 |
| 5 | 유대 | 호감도 100, 3장 완료 | **호감도 CG 장면** | 2분 | 궁극기 연출 강화, 전용 주사위 스킨, CG 갤러리 |

- 단계가 열리면 길드 홀의 그 동료 머리 위에 표시가 뜬다. 언제 볼지는 플레이어가 고른다. 매주 의뢰와 경쟁하지 않는다
- **호감도는 다음 단계를 보기 전까지 그 문턱에서 멈춘다.** 서브 스토리를 건너뛰고 수치만 오르는 일이 없다
- 장 완료 조건은 이야기 속도를 맞추려는 것. 메인 스토리에서 아직 안 밝혀진 비밀을 서브 스토리가 먼저 말하지 않게 한다
- 연애는 4~5단계에서 **암시 정도.** 노골적 묘사는 없다. 단장은 화면에 나오지 않는다

### 6.2 호감도를 얻는 법

**① 데려가 키우기 (주된 길, 전체의 약 70%)**

| 한 일 | 호감도 |
|---|---|
| 그 동료를 파티에 넣고 의뢰 페이지를 끝냄 | +6 (결전 +10) |
| 그 동료가 판정을 맡음 | 성공 +2, 실패 +1 ("믿고 맡겨 줬다") |
| 행운 주사위를 그 동료의 판정이나 공격에 써 줌 | +2 |
| 전투 활약: 궁극기, 마지막 일격, 동료를 지켜 냄 | 각 +1 (페이지당 최대 +4) |
| 레벨이 오름 | +3 |

**② 선물 (보조, 약 30%. 벤치 동료를 따라잡게 해 주는 길)**
- 선물은 의뢰 보상과 마을 상점에서 얻는다
- 동료마다 **좋아함 +6 / 보통 +3 / 별로 +1**. 별로인 선물에도 그 동료다운 한마디가 나온다 (개성을 보여 주는 장치)
- 한 동료에게 **주말마다 한 번**만 줄 수 있다 (선물 몰아주기 방지)
- 파티에 못 데려간 동료도 선물로 천천히 따라온다. 하지만 3단계 개인 의뢰는 그 동료를 데려가야 끝나므로, 결국 **직접 키우는 것**이 가장 빠르다

**속도 기준 (조정용):** 한 장에 의뢰 페이지 5~6개를 같이 하면 데려가기만으로 약 50~60, 선물로 약 20~25가 쌓인다. 주력 동료는 3장 끝 무렵 5단계에 닿고, 벤치 동료는 선물과 몇 번의 동행으로 3~4단계까지 따라온다.

### 6.3 동료별 선물 취향 (가안)

| 동료 | 좋아함 | 별로 | 한마디 예 |
|---|---|---|---|
| 리나 | 기사 이야기책, 요리 재료(못하지만 좋아함) | 화려한 장신구 | "이, 이걸로 오늘 저녁은 제가…!" |
| 세실 | 사과, 반짝이는 동전·장신구 | 책 | "…헤, 단장치고 보는 눈 있네." |
| 아델하이트 | 책, 향 좋은 차, 양초 | 운동 도구 | "…나쁘지 않아. 고마워." |
| 미리엄 | 꽃, 향유 | (없음, 다 기뻐함) | "어머, 저를 생각해 주셨군요." |
| 로웬 | 악보, 류트 줄 | 시끄러운 것 | "이건 노래로 갚을게요~" |
| 고드릭 | 독한 술, 낚시 도구 | 단 과자 | "…마셔야지." |
| 이졸데 | 바느질 도구(반전), 장미 | 싸구려 향수 | "흥, 받아는 드리죠." |
| 카샤 | 꿀 과자(반전), 스콜 간식 | 향수 | "…달다. 또 있어?" |

### 6.4 NPC 3단계 이야기: 마르타와 노라 (2026-10-17 사용자 결정)

> 동료가 아닌 NPC 중 **마르타(N01, 선술집 주인)**와 **노라(N14, 길드 부관)** 둘만 (대장장이·잡화점 주인 같은 다른 NPC는 호감도 없음, 2026-10-17 사용자 확인) 호감도와 짧은 **3단계 이야기**를 가진다. 둘 다 **전투에 나오지 않고 특별한 기믹도 없다** (2026-10-17 사용자 지시: 마르타의 '은퇴한 모험가로 손님 전투 참전' 기믹을 뺐다). 장면은 기존 스탠딩 3종으로만 만든다. 엔딩·분기 없음 (v0.5)
>
> - 장면 길이: 단계마다 1분 안팎
> - 호감도는 동료와 같이 **다음 단계를 보기 전까지 문턱에서 멈춘다**
> - 선물은 동료와 같은 규칙(주말마다 한 번, 좋아함 +6 / 보통 +3 / 별로 +1)

**마르타의 호감도**
- **식재료 납품**: 약초 1개를 선술집에 가져다주면 오른다 (+6, 장부 한 쪽에 한 번). 잡화점이 열리면 고기·버섯·꿀 같은 식재료로 넓힌다
- 길드가 **마을 근처 의뢰**를 끝낼 때마다 조금 오른다 ("길드 덕에 손님이 늘었어!")

| 단계 | 이름 | 여는 조건 | 내용 | 보상 |
|---|---|---|---|---|
| 1 | 단골 | 호감도 30 | 마르타가 길드 몫으로 외상 장부를 펼친다. 잔소리와 함께 남은 음식을 싸 준다 | 야영 칸에서 행운 주사위 +1 더 |
| 2 | 그때 그 국자 | 호감도 60, 1장 완료 | 30년 전 용사 일행이 이 선술집 단골이었다는 이야기. 에드릭이 외상을 안 갚고 사라졌다며 투덜대지만, 그 장부를 아직 버리지 못했다 | 주말 소식에 "선술집 소문" 한 줄 추가 (다음 주 의뢰 힌트) |
| 3 | 길드의 식탁 | 호감도 100, 2장 완료 | 마르타가 선술집 한가운데 탁자를 "하웰 길드 자리"로 비워 두고, 오래된 외상 장부를 길드 앞에서 찢는다. "이제 너희가 이 마을 단골이야." | 의뢰 출발 때 행운 주사위 +1 (결전 포함) |

**노라의 호감도**
- 매주 **주말 장부**를 마칠 때마다 조금 오른다 (위탁 의뢰를 하나도 놀리지 않았으면 더)
- **재건 공사**를 한 단계 마칠 때마다 크게 오른다
- 선물. 좋아함: 고급 잉크·깃펜, 옛 길드 기록물 / 별로: 싸구려 장신구

| 단계 | 이름 | 여는 조건 | 내용 | 보상 |
|---|---|---|---|---|
| 1 | 부관의 스크랩북 | 호감도 30 | 노라가 어릴 때부터 모은 옛 하웰 길드 의뢰서 스크랩북을 들킨다. 사실 길드의 오랜 팬이었다 | 장부 화면에 다음 주 예상 수입이 보인다 |
| 2 | 수도에서 온 편지 | 호감도 60, 1장 완료 | 수도 상회의 옛 상사가 좋은 조건으로 돌아오라는 편지를 보낸다. 노라는 웃으면서 답장을 쓴다: "하웰 부관 자리가 더 바빠서요." | 재건 공사 금화 비용 −5% |
| 3 | 하웰의 부관 | 호감도 100, 2장 완료 | 노라가 그동안 '임시 부관'으로 적어 온 길드 명부 첫 장을 고쳐, 자기 이름을 정식 길드원으로 적는다 | 위탁 의뢰 보수 +10% |

- 새로 필요한 아트: 노라 스탠딩 3종(기본·긍정·부정, S34). 마르타는 이미 있는 스탠딩 3종을 쓴다

### 6.5 일반 대화와 호감도 대화 (니케식, 2026-10-17 사용자 요청)

| | 일반 대화 | 호감도 대화 |
|---|---|---|

| 의뢰 1개 | 10~20분 (모바일 한 세션에 맞음). 이 중 이야기 장면은 1분 안팎 |
| 결전 의뢰 | 30~40분 |
| 챕터 1개 | 일반 의뢰 4~5개 + 결전 = 약 1.5~2시간 |
| 메인 스토리 (무료) | 챕터 3~4개 = **5~8시간** |

## 8. 제작 메모 (1인 개발 관점)

- **고르지 않은 의뢰의 결과는 "소식 텍스트 + 상태 변화"로만 처리**한다. 결과 장면을 따로 만들지 않아 비용이 낮다
- 챕터당 의뢰 8~10개 중 절반은 기존 전투 맵과 배경을 재사용한다
- 연대기 페이지, 길 그리기, 여백 낙서, 완성 장식은 전부 **코드(SVG)로 그린다**(Claude 담당). 여백 낙서는 모티프 30~50개를 만들어 조합한다
- 지역 지도 일러스트(`bg_world_map`)는 "이번 주 의뢰" 화면의 바탕으로 쓴다
- **과거 회상 추가 아트:** 과거 길드원 3명(에드릭, 알도, 젊은 고드릭)의 스탠딩·SD, 모르칸트 스탠딩, 방 배경 4장, 전성기 길드 하우스 배경. 회상은 기존 전투 맵을 재사용한다
- 회상의 세피아 연출은 셰이더로 처리한다(배경과 SD에 색조 필터). 회상 전용 배경을 따로 칠하지 않는다

## 9. 2026-10-17 추가: 시간, 동료 화면, 대장간·잡화점, 밸런스

### 9.1 시간 개념: 날짜 없음 (사용자 결정)
- 게임에 **주·달·계절 같은 날짜는 없다.** 한 바퀴(의뢰 고르기 → 의뢰 → 장부 마감 → 소식)를 **장부 한 쪽**이라 부른다. 화면에는 "장부 N쪽"으로만 나온다. 1장이 몇 년이 걸렸든 상관없다
- "한 번" 제한(호감도 대화, 선물, 마르타 납품)은 모두 **장부 한 쪽에 한 번**
- 저장·불러오기 메뉴는 없다. **화면이 바뀔 때마다 자동 저장**, 제목 화면은 **게임 시작** 버튼 하나 (저장이 있으면 그 자리에서 이어서)

### 9.2 동료 화면 (길드 하우스 아래 메뉴 '동료')
- 왼쪽 동료 목록 · 가운데 스탠딩(누르면 일반 대화 한 줄) · 오른쪽 카드 두 쪽
- **성장:** 파티 넣기/빼기(최대 3), 레벨·경험치, 능력치(체력·방어·위력·속도·판정 보정), 장비 2칸, 스킬 4개
- **유대:** 호감도, 서브 스토리 5단계(6.1절 표 그대로), 이야기 보기, 호감도 대화, 선물
- 레벨: 의뢰 성공 100 · 절반 60 · 결전 150 경험치. 다음 레벨까지 80 + 레벨×40. 레벨마다 체력 +2, 짝수 레벨마다 스킬 위력 +1. 최고 10
- 체험판에는 서브 스토리 1·2단계 장면만 있다 (3단계부터 1장 완료 뒤)

### 9.3 대장간 (대장장이 볼프람, N12)
- 동료마다 무기 하나, 방어구 하나. 단계: 낡은 → 철(150·철 1) → 강철(400·철 3, 공사 2단계 뒤) → 명장(900·철 5, 공사 4단계 뒤)
- 무기: 단계마다 스킬 위력 +1. 방어구: 단계마다 방어 +1. 강화(+1~): 무기 위력 +1 / 방어구 체력 +2. 강화 상한은 무기고
- 새 장비를 사면 쓰던 장비는 30% 값에 판다 (장비 팔기)
- 대장장이는 2026-10-17 사용자 지시로 그레타(30대 여자) → **볼프람(40대 중반 남자)**으로 바뀌었다. 미형이 아니라 거친 대장장이 얼굴 (art/steps/S35.md)

### 9.4 잡화점 (핍)
- 소모품: **회복약** 30 (전투 행동: 동료 하나 체력 10, 판정 없음), **행운 부적** 60 (의뢰를 떠날 때 빈 행운 주사위가 있으면 저절로 하나 써서 +1)
- 선물(6.3절 취향): 기사 이야기책, 사과 바구니, 반짝이 장신구, 향 좋은 찻잎, 밀랍 양초, 고급 잉크와 깃펜, 들꽃 다발
- 식재료: 훈제 고기, 버섯 바구니, 꿀단지 → 마르타 납품, 주방 도시락

### 9.5 밸런스 (godot/sims/econ_sim.tscn)
- 3장 = 장부 약 10쪽 (1장 3쪽 · 2장 3쪽 · 3장 4쪽, 각 장 마지막 쪽은 결전)
- 메인 의뢰 성공 보상: 1장 250 · 2장 350 · 3장 450 금화. 결전 보상 400 · 600 · 800
- 위탁 의뢰 보상 = 필요 실력 × 6 (보수 몫을 뗀다). 의뢰 난도는 길드 등급 + 공사 단계/2 만큼 오른다
- 결과(300회 시뮬레이션, 지원자를 꾸준히 뽑고 시설도 사는 보통 플레이): 10쪽 안에 완공 56%, 완공 시점 중앙값 9쪽, 빚은 장마다 다 갚는다. 공사만 몰아 하면 더 빠르다

### 9.6 1장 구성: 장부 3쪽 (2026-10-17)
