# 07. 오마주와 표절 사이: 독자성 원칙 v0.1

> 2026-10-15 사용자 지시: BG3 오마주는 좋지만 용어나 컨셉이 표절까지 가면 안 된다. 적절히 우회한다.
> 이 문서는 **기획, 아트, UI, 대사, 마케팅 전부**에 적용한다. 새 시스템이나 용어를 만들 때 여기 체크리스트를 먼저 본다.

## 1. 원칙: 장르는 빌리고, 고유한 것은 빌리지 않는다

| 빌려도 되는 것 (장르 공통) | 빌리지 않는 것 (BG3·D&D 고유) |
|---|---|
| d20 굴림 + 보정치 ≥ 목표값, 두 번 굴려 높은/낮은 값 | 고유명사: 세계, 도시, 신, 종족, 괴물, 인물, 주문 이름 |
| 사각 그리드 턴제, 밀치기, 고저차, 기름+불 같은 환경 반응 | D&D 용어를 그대로 쓴 화면 문구: AC, DC, 세이빙 스로, 기회 공격, 영감, 숙련 |
| 선택지 분기, 동료 호감도, 세력 평판, 캠프 | BG3의 상징적인 연출: 화면 가운데 커다란 d20과 DC 원, "○○가 좋아합니다" 팝업, 긴 휴식/짧은 휴식 |
| 능력치 판정으로 대화 선택지 열기 | 행동/보조행동/반응, 주문 슬롯, 클래스 이름과 서브클래스 구조 |

게임 규칙 자체(d20, 유리/불리 등)는 저작권 대상이 아니다. 그래도 **겉으로 드러나는 이름과 연출은 전부 우리 것으로** 만든다. 플레이어가 "BG3를 생각나게 한다"고 느끼는 건 괜찮지만, "BG3를 베꼈다"고 느끼면 안 된다.

## 2. 우리 용어집 (화면에 보이는 말)

기획 문서 안에서는 설계 편의상 AC, DC 같은 약어를 계속 쓴다. **화면, 대사, 도움말, 스토어 문구에는 아래 오른쪽 말만 쓴다.**

| 설계 약어 (문서 내부) | 화면 표기 (ko) | en | ja |
|---|---|---|---|
| AC | **방어** | Guard | 守り |
| DC | **난이도** | Difficulty | 難易度 |
| 세이빙 스로 | **저항** | Resist | 抵抗 |
| 어드밴티지 / 디스어드밴티지 | **유리 / 불리** | Favored / Hindered | 有利 / 不利 |
| 기회 공격 | **빈틈 공격** | Opening Strike | 隙突き |
| 자연 20 / 자연 1 | **대성공 / 대실패** | Triumph / Mishap | 大成功 / 大失敗 |
| 영감 | **행운 주사위** (우리 고유 시스템, 2026-10-16 "운명 주사위"에서 바꿈) | Luck Dice | 幸運のダイス |
| 숙련 / 기술 | **특기** | Talent | 特技 |
| 힘 / 민첩 / 지능 / 매력 | 힘 / 민첩 / 지능 / 매력 (STR 같은 영문 약자는 쓰지 않는다) | Might / Finesse / Wit / Presence | 力 / 器用 / 知力 / 魅力 |
| 승인 반응 | **SD 감정 아이콘** (말풍선 하나, 문구 없음) | — | — |
| 긴 휴식 | **야영** (휴식 종류는 하나뿐) | Camp | 野営 |

- 직업은 장르 일반 단어(기사, 도적, 마법사, 순례자 사제, 음유시인, 석궁수, 결투가, 사냥꾼)만 쓴다. 팔라딘, 워락, 소서러 같은 D&D 클래스명과 서브클래스 구조는 쓰지 않는다
- 스킬과 주문은 우리 이름만 쓴다(방패 강타, 연막탄, 서리 사슬, 금서 해방 …). 인명이 붙은 주문명이나 D&D 주문명을 빌리지 않는다

## 3. 연출: 주사위 굴림 화면은 우리 방식으로

- BG3의 "화면 가운데 큰 d20 + DC 원" 연출은 쓰지 않는다
- 우리 굴림 연출: **길드 등불 아래 나무 쟁반**에 주사위가 굴러 떨어지고, 굴리기 전에 **성공률(%)**을 먼저 보여 준다. 행운 주사위는 쟁반 옆 등불 받침에 놓인다
- 동료 반응은 문구 팝업 대신 SD 말풍선 감정 아이콘(♪, 💢, …)으로 1초만 보여 준다

## 4. 세계관과 이야기

- 세계, 도시, 신, 종족, 괴물은 전부 우리 것이다. 지금 적(도적, 늑대, 궁수, 붉은수염)처럼 **일반 명사 + 우리 고유명**으로 간다
- D&D 고유 괴물(마인드 플레이어, 비홀더, 아울베어, 디스플레이서 비스트, 기스양키 등)과 그 변형은 쓰지 않는다
- 메인 줄거리에 BG3의 핵심 장치를 쓰지 않는다: 머릿속 기생체, 죽은 신의 선택받은 자, 신들의 대리전, 기억을 잃은 주인공, 정신 지배 집단
- 우리 핵심은 **평화 30년 뒤 괴수가 돌아온 세계 + 용사의 몰락한 길드를 물려받은 싸울 줄 모르는 서기 단장 + 흑기사 모르칸트 + 네 세력**이다 (02-game-concept.md 8.0절)

### 동료 체크

동료가 BG3 동료와 1:1로 겹치지 않게 한다(외형 + 직업 + 비밀이 한꺼번에 겹치면 안 된다).

| 동료 | 확인 결과 |
|---|---|
| 세실 (은발 도적) | BG3의 은발 도적은 남성 흡혈귀 귀족. 세실은 소매치기 톰보이라 겹치지 않음. **흡혈귀, 귀족 출신 설정은 넣지 않는다** |
| 미리엄 (비밀이 있는 사제) | "정체를 숨긴 사제"는 겹칠 위험이 있다. 비밀을 정할 때 **어둠의 여신 밀정, 기억 상실** 방향은 쓰지 않는다. 우리 세력(새벽빛 교회)과 연결된 비밀로 정한다 |
| 아델하이트 (책벌레 마법사) | 금서를 읽다 쫓겨난 견습 수녀. 겹치지 않음. **몸 안의 폭탄·마법 구슬** 같은 설정은 넣지 않는다 |
| 나머지 (리나, 로웬, 고드릭, 이졸데, 카샤) | 겹치지 않음 |

## 5. 마케팅과 이름

- 스토어 페이지, 광고, 게임 안 문구에 **"발더스 게이트", "BG3", "D&D", "던전 앤 드래곤"** 을 쓰지 않는다. "주사위 판정 CRPG", "택티컬 턴제 RPG"로 소개한다
- 정식 제목에 Gate, Baldur 같은 단어를 넣지 않는다. "Project D20"은 가제다
- 기획 문서 안에서 BG3를 비교 기준으로 언급하는 것은 괜찮다(내부 자료)
