# 08. 음악

## 1. 목표

**게임을 안 해 본 사람도 사운드트랙만 따로 찾아 듣는 음악.** 2000년대 한국 온라인 RPG(테일즈위버 같은)의 뉴에이지 감성을 오마주하되, 곡과 멜로디는 우리 것으로 한다 (docs/07-originality.md).
"RPG 배경음악"처럼 들리는 무난한 곡은 쓰지 않는다. 곡마다 제목만 들어도 멜로디가 떠오르는 한 곡이어야 한다.

## 2. 방향

| 요소 | 정한 것 |
|---|---|
| 장르 | **피아노 중심 뉴에이지.** 서정적이고 맑은 소리, 재즈·퓨전 화음을 살짝 섞는다 |
| 중세 | **한 방울만.** 곡마다 하나의 악기(틴 휘슬, 하프, 류트, 피들, 허디거디 드론 등)가 한 구간에서 색을 낸다. 곡 전체를 중세 악기로 덮지 않는다 |
| 멜로디 | 한 번 들으면 흥얼거리는 주선율(훅)이 곡의 중심. 반주만 깔리는 배경음은 만들지 않는다 |
| 구성 | 반복용 곡도 인트로 → A → B → 절정 → 돌아오기로 이야기가 있는 완결된 곡. 2분 안에 감정의 기승전결 |
| 개성 | 아래 곡 카드대로 곡마다 **리드 악기·박자·조·템포·훅이 모두 다르게**. 앞 10초만 들어도 어느 곡인지 구별돼야 한다 |
| 메인 모티프 | 타이틀의 훅(등불 모티프)을 보스·회상·승리 곡에서 다른 모습으로 다시 쓴다. 사운드트랙 전체를 하나로 묶는 장치 |
| 피할 것 | EDM, 덥스텝, 트랩, 메탈, 신시사이저 패드, 에픽 트레일러풍 오케스트라, 보컬, 로파이 |

## 4. 만드는 법 (Suno 기준, ElevenLabs Music 도 같은 내용을 한 문단으로)

1. **타이틀부터.** 1번을 10번 이상 생성하고, 아래 고르는 기준을 통과하는 한 곡을 정한다. 이 곡의 훅이 사운드트랙 전체의 등불 모티프가 된다.
2. **모티프 잇기.** 6·7·8·9번은 정한 타이틀 곡을 Suno 의 Cover(리메이크) 기능에 넣고 아래 스타일로 바꿔 만든다. 그래야 같은 멜로디가 다른 모습으로 이어진다.
3. **나머지 곡**(2~5번)은 새로 만든다. 곡마다 최소 6번 생성해서 고른다.
4. 스타일 칸에는 아래 영어 문장을, 가사 칸에는 구성 태그를 넣는다. 게임·작곡가 이름은 넣지 않는다.
5. 공통 제외(Exclude Styles): `vocals, lyrics, EDM, dubstep, trap, metal, synth pad, lo-fi, epic trailer`

## 5. 고르는 기준 (이걸 통과 못 하면 다시 생성)

- [ ] 한 번 듣고 나서 **훅을 흥얼거릴 수 있다**
- [ ] **앞 10초**만 들어도 다른 곡과 구별된다
- [ ] 곡 안에 **감정의 흐름**(시작 → 고조 → 마무리)이 있다. 같은 반주만 맴돌지 않는다
- [ ] 중세 악기는 **양념 수준**. 중세 음악처럼 들리면 탈락
- [ ] AI 티가 나는 소리가 없다: 음이 흐물거림, 갑자기 끊김, 뭉개진 믹스, 중간에 엉뚱한 장르로 바뀜
- [ ] 따로 플레이리스트에 넣어 들어도 **듣고 싶은 곡**이다

## 6. 게임에 넣기

- 받은 파일은 `audio/raw/` 에 원본 그대로 두고, 게임용은 OGG(96~128kbps)로 바꿔 `godot/audio/` 에 넣는다.
- 반복 곡은 반복 시작·끝 지점을 잡아 끊김 없이 돈다. 장면이 바뀌면 1초 크로스페이드.
- 웹 빌드는 파일 하나 25MiB 제한이 있어 음악은 게임 본체(pck)와 따로 내려받는다.
- 상업 이용은 유료 요금제로 만든 곡만. 무료 요금제로 만든 곡은 비교용으로만 듣고 쓰지 않는다.
- 나중에 반응이 좋으면 정한 곡들을 작곡가에게 편곡·실연 녹음을 맡겨 사운드트랙 DLC 로 낸다 (docs/02-game-concept.md 후원 항목).
