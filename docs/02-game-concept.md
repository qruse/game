## 1. 한 줄 콘셉트

> **"한 판 3분 안에 끝나는 BG3"**
> 주사위 한 번에 이야기가 바뀌는 대화와, 짧고 날카로운 택티컬 전투를 모바일에서 즐긴다.
> 어떤 동료를 데려가느냐에 따라 열리는 선택지가 달라진다.

## 2. 디자인 기둥 (Pillars)

모든 기능 결정은 아래 세 기둥에 맞는지 확인한다. 셋 중 어디에도 해당하지 않는 기능은 넣지 않는다.

1. **주사위가 이야기를 만든다.** 대화와 전투 모두 d20 판정으로 결과가 갈리고, 실패도 재미있는 전개가 된다(fail forward).
2. **3분 택티컬.** 전투 한 판은 3~5라운드, 2~3분 안에 끝난다. 짧지만 위치 선정과 환경 활용으로 판이 뒤집힌다.
3. **동료가 열쇠다.** 동료마다 가진 특기가 대화 선택지, 루트, 전투 해법을 연다. 동료와의 관계(호감도)가 개인 스토리를 연다.

## 3. 핵심 루프

> **v0.4 변경:** 진행 구조를 "다 못 하는 의뢰 + 써 내려가는 연대기 + 봉인된 방과 과거 회상"으로 바꿨다. 상세는 [04-game-flow.md](04-game-flow.md).

```
[1~3분]   칸 1개: 대화(주사위 판정) / 전투 / 탐색 / 캠프
             ↓
[10~20분] 의뢰 1개 = 연대기 한 페이지. 판정과 선택의 결과로 길이 써 내려가진다
             ↓
[한 주]   의뢰 3~4개 중 2개만 고른다. 안 간 의뢰는 결과가 남는다
             ↓
[챕터]    3주 + 결전 의뢰 → 길드 복구 → 봉인된 방이 열리고 과거 회상을 플레이
             ↓
[유료]    동료 팩으로 새 동료와 개인 의뢰 추가 / 확장팩으로 새 지역 추가
```

### 3.1 연대기 페이지 구조

- 의뢰 하나는 칸 4~8개(결전은 10~12개)로 된 **필사본 페이지**다. 처음에는 첫 칸만 보이고, 판정과 선택의 결과로 다음 칸이 써진다
- **다이아몬드 구조:** 페이지 안에서는 갈라지고 끝에서 합류한다. 선택 결과는 플래그로 저장해 이후 대사, 다음 주 의뢰, 결전 조건, 에필로그에 반영한다. 분기가 기하급수로 늘어나는 것을 막는 1인 개발용 필수 장치다

## 4. 주사위 판정 시스템

### 4.1 기본 규칙

- **d20 + 보정치 ≥ 난이도(DC)** 이면 성공한다
- 판정 전에 **성공 확률(%)을 화면에 보여 준다.** 모바일 유저가 이해하기 쉽게 하기 위해서다
- 자연 20은 대성공(추가 보상, 특수 대사), 자연 1은 대실패(특수 전개)다

### 4.2 능력치와 특기 (BG3의 6능력치·18기술을 단순화)

| 능력치 | 대표 특기 태그 |
|---|---|
| 힘 | 위협, 운동 |
| 민첩 | 은신, 손재주(자물쇠, 함정) |
| 지능 | 지식, 조사, 마법학 |
| 매력 | 설득, 기만, 공연 |

- 파티에 해당 특기를 가진 동료가 있으면 **보정치가 붙고 전용 선택지가 열린다.**
  - 예: `[손재주 · 리나] 자물쇠를 딴다 (성공률 75%)`
- 판정은 **가장 잘하는 동료가 대신 굴린다.** BG3처럼 누가 말할지 고르는 번거로움을 줄인다

### 4.3 운명 주사위 (영감 토큰을 대체, 2026-10-15)

- 의뢰를 출발할 때 d20 **2개**를 미리 굴려 **손에 든다.** 캠프에서 1개 더, 자연 1이 나오면 1개 더 (**최대 3개**)
- 대화 판정이나 공격에서 굴리는 대신 **들고 있는 눈을 골라 놓는다.** 높은 눈은 우리 굴림에
- **낮은 눈은 적에게 "운명 낙인"으로 찍어** 그 적의 다음 굴림을 망친다
- "18을 지금 설득에 쓸까, 보스까지 아낄까"가 이 게임의 대표 고민이 된다
- **운명 주사위와 재굴림은 절대 돈이나 광고로 팔지 않는다.** 주사위 스킨(겉모습)만 판다
- 상세 규칙: [05-combat.md](05-combat.md) 5.4절

**세계관 연결 (확정, 2026-10-15):** 은빛 등불 길드의 단장만이 등불을 통해 **"운명을 엿보는" 힘**을 물려받는다. 운명 주사위는 그 힘의 게임적 표현이다.
- 전 길드장 에드릭도 같은 힘을 가졌다
- **모르칸트가 길드를 무너뜨린 이유가 이 힘이다.** 회상(봉인된 방)에서 그가 힘에 집착해 가는 과정이 드러난다
- 플레이어(새 단장)가 녹슨 열쇠와 함께 이 힘을 이어받는 것이 1장 오프닝이다
- 최종장에서 흑기사(모르칸트)와의 대결은 "운명을 엿보는 자"끼리의 싸움이 된다

## 5. 전투: "빠른 BG3"

### 5.1 템포 규칙

| 항목 | BG3 | 우리 게임 |
|---|---|---|
| 맵 | 자유 이동 3D | **7×5 사각 그리드** (가로 화면, 탑다운) |
| 파티 | 4인 | **3인** (캠프에서 교체 가능) |
| 턴 순서 | 개인 이니셔티브 | **진영 턴** (아군 전원 → 적 전원), 아군 행동 순서는 자유 |
| 행동 | 행동 + 보조행동 + 반응 + 이동 | **이동 1 + 행동 1** (반응은 자동) |
| 명중 | d20 vs AC | 같다. 대신 **명중률 %를 미리 표시**한다 |
| 전투 길이 | 10~30분 | **3~5라운드, 2~3분** |
| 반복 | 수동 | 2배속, 한 번 클리어한 전투는 재방문 시 건너뛰기 가능 |

### 5.2 BG3다움을 남기는 장치 (범위를 좁게)

1. **환경 콤보 3종만** 넣는다: 기름+불(화염 지대), 물+전기(감전), 높은 곳(명중 보너스)
2. **밀치기:** 낭떠러지, 함정, 화염 지대로 밀어 넣는다. 한 방에 판이 뒤집히는 쾌감을 준다
3. **대화로 전투 바꾸기:** 전투 전 판정 결과가 전투 조건을 바꾼다(기습 성공 → 선공, 설득 성공 → 적 일부 이탈)

### 5.3 캐릭터 전투 구성

- 동료 1명은 **기본 공격 + 스킬 2개 + 궁극기 1개**로 구성한다
- 역할: 탱커 / 근접 딜러 / 원거리 딜러 / 서포터 / 컨트롤러
- 전투 연출은 SD Spine 애니메이션으로 하고, 궁극기만 컷인 일러스트를 쓴다(서브컬처 쾌감 포인트)

## 6. 선택과 결과 (가챠를 빼서 다시 얻은 자유)

가챠가 없으니 **BG3처럼 진짜 결과가 있는 선택**을 다시 넣을 수 있다. 장르의 핵심 재미를 되찾은 것이 이번 BM 변경의 가장 큰 설계상 이득이다.

| 선택이 바꾸는 것 |
|---|
| 챕터 결말과 다음 노드 |
| NPC·세력과의 관계 |
| 동료 호감도, 개인 스토리 진행 |
| **동료의 이탈·사망** (무료 동료는 메인 스토리에서, 유료 동료는 자기 개인 퀘스트 안에서) |
| 보상의 종류, 에필로그, 엔딩 도감 |

### 6.1 유료 동료를 다루는 원칙

- 유료 동료도 이탈하거나 죽을 수 있다. 다만 **플레이어가 그 동료의 개인 퀘스트에서 명확한 선택을 했을 때만** 일어나고, 선택지 옆에 경고 표시를 한다
- 메인 스토리의 무작위 사건이나 판정 실패 한 번으로 유료 동료를 잃게 하지 않는다
- **챕터 리플레이**와 **세이브 슬롯**을 제공해서 다른 결말을 볼 수 있게 한다
- 유료 동료가 없어도 **메인 스토리의 모든 특기 판정은 무료 동료로 해결할 수 있다.** 유료 동료가 여는 것은 추가 루트, 전용 대사, 추가 보상이다

## 7. BM 설계: 메인 무료 + 콘텐츠 유료

### 7.1 무료 / 유료 구분

| 구분 | 내용 | 가격대(초안) |
|---|---|---|
| **무료** | 메인 스토리 전체, 무료 동료 5~6명, 기본 주사위 스킨 | 0원 |
| **동료 팩** | 동료 1명 + 개인 퀘스트(노드 8~12개) + 캠프 이벤트 + 전용 엔딩 | 3,300~5,500원 |
| **확장팩** | 새 지역 캠페인(챕터 2~3개 분량) + 동료 1~2명 + 신규 적 | 9,900~15,000원 |
| **꾸미기** | 주사위 스킨(BG3식), 동료 코스튬(SD) | 1,100~3,300원 |
| **후원 번들** | 사운드트랙, 아트북, 크레딧 등재 등 팬 상품 | 선택 |
| 광고 (모바일) | **보상형 광고만.** 강제 광고, 배너, 전면 광고는 넣지 않는다 | — |

> 가격은 출시 시장 시세를 다시 조사해서 정한다.

### 7.1.1 보상형 광고 규칙

- 광고를 보지 않아도 **게임 진행과 재미에 손해가 없어야** 한다. 광고 보상은 "조금 빨라지는 것"이지 "없으면 막히는 것"이 아니다
- 보상 후보: 캠프 휴식 보너스(다음 전투 체력 +), 소량 재화, 상점 목록 새로고침
- **운명 주사위, 판정 재굴림은 광고 보상으로도 주지 않는다**(4.3절 원칙)
- 하루 시청 횟수에 상한을 둔다(예: 5회)
- 유료 상품을 하나라도 산 유저에게는 광고 없이 같은 보상을 주는 방안을 검토한다(구매 동기와 감사 표시)

### 7.1.2 Steam판 차이

- Steam판은 **광고가 없다.** 광고 보상과 같은 효과는 기본으로 주거나 무시해도 될 만큼 작게 설계해서 두 버전의 밸런스를 맞춘다
- Steam판의 메인 스토리도 **무료(Free to Play)**로 내고, 동료 팩·확장팩은 Steam DLC로 판다
- ❓ 모바일과 Steam 사이에 세이브와 구매 내역을 연동할지는 각 스토어 정책을 확인한 뒤 정한다

### 7.2 이 BM을 고른 이유 (가챠 대비)

| 항목 | 가챠 | 메인 무료 + DLC |
|---|---|---|
| 업데이트 압박 | 4~6주마다 신캐가 없으면 매출이 무너진다 | 동료 팩·확장팩을 **준비된 시점에** 낸다 |
| 법적 의무 | 확률 공개, 3배 손해배상 리스크, 천장 설계 | 거의 없음 (일반 결제와 환불 규정만 지키면 된다) |
| 서버 | 뽑기를 서버에서 처리하고 로그를 보관해야 한다 | 결제 영수증 검증만 하면 된다. **오프라인 플레이가 가능하다** |
| 설계 자유도 | 과금 캐릭터를 잃게 할 수 없다 | 진짜 결과가 있는 선택이 가능하다 (6절) |
| 유저 인식 | "또 가챠냐" 피로감 | "착한 BM" 마케팅 포인트가 된다 |
| **매출 상한** | 높다 (소수 고과금 유저) | **낮다** (1인당 지출에 상한이 있다) |

### 7.3 매출 리스크와 보완책

- 무료로 받은 유저 중 실제로 돈을 쓰는 비율은 보통 **한 자릿수 %**다. 슈퍼 마리오 런은 두 자릿수를 기대했지만 그 절반 이하에 그쳤다. 따라서 **다운로드 수가 매출을 결정한다**
- 보완책은 다음과 같다
  1. **Steam(PC) 동시 출시 (확정).** 뱀서도 Steam에서 먼저 터졌고 모바일은 나중에 무료로 냈다. 프로젝트 문(한국 개발사)의 Library of Ruina는 Steam 프리미엄 서브컬처 게임으로 추정 80만~300만 장을 팔았다
  2. 메인 스토리 끝부분에서 **동료 팩 미리보기**(동료가 잠깐 합류하는 이벤트)로 구매 동기를 만든다
  3. **첫 구매 장벽을 낮춘다.** 첫 동료 팩을 할인하거나 "스타터 번들"을 둔다
  4. 개발일지, 데모, 커뮤니티로 출시 전 팬층을 만든다

## 8. 세계관 / 톤: A. 모험가 길드 판타지 (확정)

> 정통 판타지 세계에서 플레이어는 **신생 모험가 길드의 단장**이 되어 동료를 모으고 의뢰를 해결한다.

### 8.1 이 세계관이 시스템과 맞물리는 지점

| 시스템 | 세계관 안에서의 모습 |
|---|---|
| 챕터 맵 / 노드 | 길드가 받은 **의뢰**. 의뢰 게시판에서 고르고 현장으로 떠난다 |
| 캠프 | **길드 하우스.** 동료와 대화하고, 호감도 이벤트가 일어나고, 장비를 정비한다. 시설을 늘리면 길드 하우스가 커진다 |
| 동료 영입 | 길드 **입단 면접/스카우트.** 무료 동료는 메인 스토리에서 합류하고, 유료 동료 팩은 "특별 스카우트 의뢰"로 등장한다 |
| 동료 이탈·사망 | 길드원이 신념 차이로 **탈퇴**하거나, 의뢰 중 목숨을 잃는다 |
| 확장팩 | 길드가 **새 지역 지부**를 낸다. 지역마다 새 세력과 새 문제가 있다 |
| 주사위 스킨 | 길드 문장이나 동료 테마가 들어간 주사위 |

### 8.2 "흔하다"는 약점을 보완할 차별화 훅 ❓ (하나 고르거나 섞는다)

| 훅 | 내용 | 효과 |
|---|---|---|
| **H1. 몰락한 명문 길드 재건** | 한때 왕국 최고였던 길드가 한 사건으로 몰락했다. 주인공은 이름만 남은 길드를 물려받는다. "그때 무슨 일이 있었나"가 메인 미스터리다 | 성장 서사가 선명하다. 옛 길드원이 동료/적으로 나온다 |
| **H2. 길드 간 경쟁** | 도시에 여러 길드가 있고, 의뢰를 두고 경쟁한다. 라이벌 길드의 선택이 플레이어 선택에 반응한다 | BG3식 세력 관계와 선택 결과를 보여 주기 좋다 |
| **H3. 길드의 비밀 의뢰인** | 길드에 정체불명의 후원자가 비밀 의뢰를 넣는다. 의뢰를 받을지, 의뢰인을 파헤칠지 선택한다 | 도덕적 선택(BG3식 회색 선택지)을 만들기 쉽다 |

**결정: H1 (몰락한 명문 길드 재건).** 재건 서사는 동료가 하나씩 모이는 구조와 잘 맞는다. 라이벌 길드(H2)는 확장팩용 소재로 남겨 둔다.

**세력:** 왕관(왕국과 영주), 새벽빛 교회, 금저울 상회, 회색 쥐(뒷골목)가 모두 은빛 등불을 원한다. 선택에 따라 우호도가 바뀌고 혜택·결전 지원군·엔딩으로 돌아온다 ([06-factions.md](06-factions.md)).

**중세 분위기 원칙:** 기사도, 봉건 영주, 교회, 길드 조합, 문장(紋章)을 세계의 뼈대로 쓴다. 화약과 현대식 말투는 넣지 않는다. UI와 텍스트도 양피지, 필사본, 인장 같은 중세 소재로 통일한다.

### 8.3 톤 가이드

- 기본 톤은 **밝은 모험물**이다. 동료끼리의 만담과 캠프 이벤트는 서브컬처답게 가볍고 귀엽게 간다
- 의뢰 안의 선택은 **BG3처럼 무겁게** 간다. 쉬운 정답이 없는 선택을 챕터마다 1~2개 넣는다
- 밝은 일상과 무거운 선택의 낙차가 이 게임의 정서적 리듬이다

## 9. 아트 방향 (1인 개발 비용 기준)

> **결정 (2026-10-15):** 인게임 도트는 하지 않는다. 도트는 코스튬마다 모든 프레임을 다시 그려야 해서 꾸미기 BM과 충돌하고, 외주 비용도 SD Spine과 큰 차이가 없다. 인게임은 **SD 2D 컷아웃 애니메이션**, 대화는 **서브컬처 일러스트**로 간다.
> **변경 (2026-10-15): 외주 없음.** 일러스트(스탠딩, SD, 배경, CG, 아이콘)는 **Codex + 이미지 생성 모델**로 만들고, UI·이펙트·애니메이션·주사위는 Claude가 코드로 만든다. 결과물은 AI 생성물이므로 **Steam의 AI 콘텐츠 공개 의무에 따라 상점 페이지에 밝힌다.**
> 화풍: 서브컬처 애니풍 캐릭터 + 짙은 중세 분위기. UI는 중세 필사본풍. 작업 지침과 전체 목록은 [art/README.md](../art/README.md)에 있다.

| 용도 | 방식 | 비고 |
|---|---|---|
| 전투 | **SD 2D + Spine** | 공통 리그를 재사용해 캐릭터당 비용을 낮춘다. 트릭컬식 |
| 대화 | 스탠딩 일러스트 + 표정 4~6종 | 외주 |
| 궁극기 | 컷인 일러스트 1장 | 서브컬처 매력 포인트 |
| 맵 | 타일셋 기반 탑다운 | 에셋 스토어 + 수정 |
| 생성형 AI | **캐릭터 일러스트와 스토리에는 쓰지 않는다** | 코드, 툴, 내부 목업에만 쓴다 |
