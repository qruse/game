## 1. 한 줄 콘셉트

> **"한 판 3분 안에 끝나는 BG3"**
> 주사위 한 번에 이야기가 바뀌는 대화와, 짧고 날카로운 택티컬 전투를 모바일에서 즐긴다.
> 어떤 동료를 데려가느냐에 따라 열리는 선택지가 달라진다.

## 2. 디자인 기둥 (Pillars)

모든 기능 결정은 아래 세 기둥에 맞는지 확인한다. 셋 중 어디에도 해당하지 않는 기능은 넣지 않는다.

1. **주사위가 이야기를 만든다.** 대화와 전투 모두 d20 판정으로 결과가 갈리고, 실패도 재미있는 전개가 된다(fail forward).
2. **3분 택티컬.** 전투 한 판은 3~5라운드, 2~3분 안에 끝난다. 짧지만 위치 선정과 환경 활용으로 판이 뒤집힌다.
3. **동료가 열쇠다.** 동료마다 가진 특기가 대화 선택지, 루트, 전투 해법을 연다. 동료와의 관계(호감도)가 개인 스토리를 연다.

## 3. 핵심 루프

> **v0.4 변경:** 진행 구조를 "다 못 하는 의뢰 + 써 내려가는 연대기 + 봉인된 방과 과거 회상"으로 바꿨다. 상세는 [04-game-flow.md](04-game-flow.md).

```
[1~3분]   칸 1개: 대화(주사위 판정) / 전투 / 탐색 / 캠프
             ↓
[10~20분] 의뢰 1개 = 연대기 한 페이지. 판정과 선택의 결과로 길이 써 내려가진다
             ↓
[한 주]   의뢰 3~4개 중 2개만 고른다. 안 간 의뢰는 결과가 남는다
             ↓
[챕터]    3주 + 결전 의뢰 → 길드 복구 → 봉인된 방이 열리고 과거 회상을 플레이
             ↓
[확장팩]  새 지역 캠페인 + 새 동료 1~2명 (출시 후, 저가)
```

### 3.1 연대기 페이지 구조

- 의뢰 하나는 칸 4~8개(결전은 10~12개)로 된 **필사본 페이지**다. 처음에는 첫 칸만 보이고, 판정과 선택의 결과로 다음 칸이 써진다
- **다이아몬드 구조:** 페이지 안에서는 갈라지고 끝에서 합류한다. 선택 결과는 플래그로 저장해 이후 대사, 다음 주 의뢰, 결전 조건, 에필로그에 반영한다. 분기가 기하급수로 늘어나는 것을 막는 1인 개발용 필수 장치다

## 4. 주사위 판정 시스템

### 4.1 기본 규칙

- **d20 + 보정치 ≥ 난이도(DC)** 이면 성공한다
- 판정 전에 **성공 확률(%)을 화면에 보여 준다.** 모바일 유저가 이해하기 쉽게 하기 위해서다
- 자연 20은 대성공(추가 보상, 특수 대사), 자연 1은 대실패(특수 전개)다

### 4.2 능력치와 특기 (BG3의 6능력치·18기술을 단순화)

| 능력치 | 대표 특기 태그 |
|---|---|
| 힘 | 위협, 운동 |
| 민첩 | 은신, 손재주(자물쇠, 함정) |
| 지능 | 지식, 조사, 마법학 |
| 매력 | 설득, 기만, 공연 |

- 파티에 해당 특기를 가진 동료가 있으면 **보정치가 붙고 전용 선택지가 열린다.**
  - 예: `[손재주 · 리나] 자물쇠를 딴다 (성공률 75%)`
- 판정은 **가장 잘하는 동료가 대신 굴린다.** BG3처럼 누가 말할지 고르는 번거로움을 줄인다

### 4.3 행운 주사위 (영감 토큰을 대체, 2026-10-15 · 2026-10-16 "운명 주사위"에서 이름 바꿈)

- 의뢰를 출발할 때 d20 **2개**를 미리 굴려 **손에 든다.** 캠프에서 1개 더, 자연 1이 나오면 1개 더 (**최대 3개**)
- 대화 판정이나 공격에서 굴리는 대신 **들고 있는 눈을 골라 놓는다.** 높은 눈은 우리 굴림에
- **낮은 눈은 적에게 "운명 낙인"으로 찍어** 그 적의 다음 굴림을 망친다
- "18을 지금 설득에 쓸까, 보스까지 아낄까"가 이 게임의 대표 고민이 된다
- **행운 주사위와 재굴림은 절대 팔지 않는다.** 주사위 스킨은 전설 장면 달성 같은 플레이 보상으로 준다
- 상세 규칙: [05-combat.md](05-combat.md) 5.4절

**세계관 연결 (2026-10-16 바꿈):** 행운 주사위는 **특별한 힘이 아니라 그냥 운**이다. 단장은 특별한 능력이 없는 평범한 사람이고, 운을 언제 쓸지 고르는 판단만 단장의 몫이다. (이전의 "등불로 운명을 엿보는 힘" 설정은 버렸다. 8.0절)
## 5. 전투: "빠른 BG3"

### 5.1 템포 규칙

| 항목 | BG3 | 우리 게임 |
|---|---|---|
| 맵 | 자유 이동 3D | **7×5 사각 그리드** (가로 화면, 탑다운) |
| 파티 | 4인 | **3인** (캠프에서 교체 가능) |
| 턴 순서 | 개인 이니셔티브 | **진영 턴** (아군 전원 → 적 전원), 아군 행동 순서는 자유 |
| 행동 | 행동 + 보조행동 + 반응 + 이동 | **이동 1 + 행동 1** (반응은 자동) |
| 명중 | d20 vs AC | 같다. 대신 **명중률 %를 미리 표시**한다 |
| 전투 길이 | 10~30분 | **3~5라운드, 2~3분** |
| 반복 | 수동 | 2배속, 한 번 클리어한 전투는 재방문 시 건너뛰기 가능 |

### 5.2 BG3다움을 남기는 장치 (범위를 좁게)

1. **환경 콤보 3종만** 넣는다: 기름+불(화염 지대), 물+전기(감전), 높은 곳(명중 보너스)
2. **밀치기:** 낭떠러지, 함정, 화염 지대로 밀어 넣는다. 한 방에 판이 뒤집히는 쾌감을 준다
3. **대화로 전투 바꾸기:** 전투 전 판정 결과가 전투 조건을 바꾼다(기습 성공 → 선공, 설득 성공 → 적 일부 이탈)

### 5.3 캐릭터 전투 구성

- 동료 1명은 **기본 공격 + 스킬 2개 + 궁극기 1개**로 구성한다
- 역할: 탱커 / 근접 딜러 / 원거리 딜러 / 서포터 / 컨트롤러
- 전투 연출은 SD Spine 애니메이션으로 하고, 궁극기만 컷인 일러스트를 쓴다(서브컬처 쾌감 포인트)

## 6. 선택과 결과 (가챠를 빼서 다시 얻은 자유)

> **v0.5 (2026-10-17): 이 절의 큰 선택(결말·관계·이탈·엔딩 도감)은 버렸다.** 0.1절 원칙대로 선택은 장면 안에서 끝난다. 아래 표는 당시 기록으로 남긴다.

가챠가 없으니 **BG3처럼 진짜 결과가 있는 선택**을 다시 넣을 수 있다. 장르의 핵심 재미를 되찾은 것이 이번 BM 변경의 가장 큰 설계상 이득이다.

| 선택이 바꾸는 것 |
|---|
| 챕터 결말과 다음 노드 |
| NPC·세력과의 관계 |
| 동료 호감도, 개인 스토리 진행 |
| **동료의 이탈·사망** (본편 동료는 메인 스토리에서, 확장팩 동료는 자기 개인 퀘스트 안에서) |
| 보상의 종류, 에필로그, 엔딩 도감 |

### 6.1 확장팩 동료를 다루는 원칙

- 확장팩 동료도 이탈하거나 죽을 수 있다. 다만 **그 동료의 개인 퀘스트에서 플레이어가 명확한 선택을 했을 때만** 일어나고, 선택지 옆에 경고 표시를 한다
- **챕터 리플레이**와 **세이브 슬롯**을 제공해서 다른 결말을 볼 수 있게 한다
- 확장팩이 없어도 **본편의 모든 특기 판정은 본편 동료로 해결할 수 있다**

## 7. BM 설계: 저가 유료 + 확장팩 (v0.4)

> 2026-10-15 사용자 결정: "저렴하게라도 게임 판매. 3,300원 정도. 동료 팩은 안 하고 확장팩만 나중에 저렴하게. 게임하면서 결제를 잘 안 할 듯."

| **확장팩** (출시 후) | 새 지역 캠페인(챕터 1~2개 분량) + 새 동료 1~2명 + 신규 적 | **2,200~3,300원** / $1.99~2.99 / ¥300~480 |
| 게임 안 결제 | **없음.** 동료 팩, 코스튬, 주사위 스킨, 재화 판매 없음 | — |
| 광고 | **없음** | — |
| 후원 (선택, Steam) | 사운드트랙, 아트북 DLC | 선택 |

- **첫 확장팩 후보:** 이졸데(C07)와 카샤(C08). 원래 동료 팩 후보였던 두 명을 확장팩 동료로 옮긴다
- **주사위 스킨, SD 코스튬**은 팔지 않고 플레이 보상(전설 장면, 엔딩, 호감도)으로 준다
- 출시 기념 할인과 확장팩 묶음은 출시 때 정한다

| 비슷한 장르 가격 | 애니풍 인디 택티컬·턴제 RPG는 $9.99 이하가 흔하고, $19.99 이상은 규모가 큰 게임이다 | 손으로 그린 비슷한 게임의 절반 수준 |
| 모바일 해금 가격 | Loop Hero 1장 무료 → $6.99, Black Book 프롤로그 무료 → $9.99, Sea of Stars $9.99, Kemco RPG $4.99~7.99 | 모바일 해금도 $4.99면 싼 편 |
| $2.99가 아닌 이유 | 한 장에 남는 돈이 약 2,300원 → 약 3,850원(1.7배). $2.99는 할인할 여지가 거의 없다(50% 할인이 $1.49). AI 표시와 합쳐지면 "싸구려"로 보이기 쉽다 | 정가 $4.99, 출시 할인으로 3,300원대 체감 |

- **조건:** 메인 스토리가 6~8시간 이상일 때 $4.99다. 체험판 기준으로 짧으면 $2.99로 낮춘다
- AI 사용은 Steam 규정대로 숨기지 않고 공개한다. 스토어 문구는 "1인 개발, 전투·이야기·시스템은 직접 설계"처럼 **사람이 만든 부분**을 앞에 둔다

### 7.2 모바일과 Steam

| 플랫폼 | 방식 |
|---|---|
| **Steam** | 유료 5,500원 / $4.99 + **무료 체험판(데모)**: 1장 앞부분. Steam 넥스트 페스트에 데모로 나간다 |
| **모바일** (확정 2026-10-15) | **무료 다운로드 → 1장 첫 의뢰까지 체험 → 정식판 해금 5,500원**(한 번만 결제, 출시 할인 동일). 유료 앱은 설치 수가 크게 줄어서, 체험 후 해금이 모바일에 더 맞다 (Loop Hero 모바일, 슈퍼 마리오 런 방식) |

- 두 플랫폼 가격은 같게 둔다
- ❓ 모바일과 Steam 사이 세이브 연동은 각 스토어 정책을 확인한 뒤 정한다

### 7.3 이 BM을 고른 이유

| 항목 | 메인 무료 + DLC (v0.3) | **저가 유료 + 확장팩 (v0.4)** |
|---|---|---|
| 결제 구조 | 게임 안에서 계속 사게 만들어야 한다 | **처음 한 번 산다.** 게임 안에 상점이 없다 |
| 설계 자유도 | 돈 낸 동료를 잃게 하기 어렵다 | 본편 동료는 이야기대로 떠나거나 죽을 수 있다 |
| 개발 부담 | 결제, 광고 SDK, 상점 UI, 영수증 검증 | **결제 1개(해금)만.** 광고 SDK가 없다. 오프라인 |
| 유저 인식 | "또 과금이냐" 걱정 | "3,300원에 끝" 이 마케팅 문구가 된다 |
| 매출 | 무료 유저 전환율이 한 자릿수 % | 산 사람은 전원 매출. 대신 **판매량이 전부**다 |

### 7.4 매출 감과 리스크

- 5,500원에서 스토어 수수료 30%를 빼면 한 장에 약 3,850원이 남는다 (할인가 3,300원이면 약 2,300원)
  - 1만 장 → 약 3,000만~3,850만 원, 5만 장 → 약 1억 5,000만~1억 9,000만 원 (할인 판매 비중에 따라)
  - 확장팩은 본편 구매자의 10~20%가 산다고 본다(유료 게임 구매자의 DLC 전환율은 무료 게임보다 높다. Monument Valley 약 10%)
- 리스크: 가격이 싸서 **판매량이 모자라면 버틸 수 없다.** 보완책은 다음과 같다
  1. **Steam 데모 + 넥스트 페스트**로 출시 전 위시리스트를 모은다
  2. 개발일지, 짧은 전투 영상(SD 동작, 컷인, 밀치기 낙사)을 SNS에 꾸준히 올린다
  3. 한국어·일본어·영어 동시 출시로 시장을 넓힌다
  4. 저가라서 **충동구매와 선물 구매**가 쉽다는 점을 스토어 문구에 쓴다

## 8. 세계관 / 톤: A. 모험가 길드 판타지 (확정)

> 정통 판타지 세계에서 플레이어는 **평화의 시대에 몰락한 시골 모험가 길드를 맡게 된 단장**이 되어 동료를 모으고 의뢰를 해결한다.

### 8.0 세계관 핵심 (확정, 2026-10-16)

> **"전투도 못 하는 내가, 어떻게 전대 용사처럼 이 세상을 구하지?"**

**연표**

| 시기 | 무슨 일 |
|---|---|
| 용사의 시대 (30년 전) | 용사 에드릭 일행이 북쪽의 재앙(이름 미정)을 쓰러뜨렸다. 일행은 기사 알도, 석궁수 고드릭, 검사 모르칸트. **하웰 모험가 길드와는 관계없다** |
| 평화의 시대 (30년 전~3년 전) | 괴수가 사라지자 모험가가 필요 없어졌다. 길드들은 잡일 심부름센터가 되거나 문을 닫았다. 용사 이야기는 아이들의 동화가 됐다 |
| 용사가 들른 날 (약 20년 전) | 여행 중 하웰에 들른 에드릭이 열두 살 무렵의 주인공을 알아보고 촌장에게 귓속말을 남긴다 (아래 주인공) |
| 하웰 길드의 몰락 (약 15년 전) | 하웰 모험가 길드는 그럭저럭 마을 의뢰로 버티던 평범한 시골 길드였다. 평화의 시대에 일이 끊겨 문을 닫았고 건물은 폐허가 됐다. 극적인 사건은 없었다 |
| 용사 일행의 해산 (약 15년 전) | 에드릭은 사라졌고 알도는 죽었다고 알려졌다. 모르칸트는 훗날 흑기사가 된다. 평화로운 세상은 크게 신경 쓰지 않았다 (자세한 사건은 다시 정한다) |
| 지금 | 3년 전부터 괴수들이 다시 날뛴다. 왕국 기사단만으로는 막지 못해 **모험가가 다시 주목받고**, 닫혔던 길드들이 하나둘 간판을 건다. 아직 황금기가 아니라 **새 시대의 새벽**이다 |

**세계의 매력:** 동화 속에만 있던 모험이 다시 현실이 되는 두근거림. 녹슨 검을 다시 꺼내는 사람들, 처음 길을 떠나는 젊은이들, 다시 붙기 시작한 의뢰서. 세계가 조금씩 다시 살아나는 것을 플레이어가 직접 본다.

**주인공 (단장)**
- **32세, 하웰 마을의 평범한 서기** (촌장 밑에서 마을 장부와 문서를 맡는다). 검을 쥐어 본 적이 없다. 특별한 힘도 없다. **일행에서 가장 약한 사람은 단장이다** (2026-10-17 사용자 확정)
- 대신 **머리로 싸우는 지능형**이다. 무기는 셋: **길드 관리**(돈, 사람, 시설, 평판을 굴려 길드를 다시 세운다), **유대**(동료 한 명 한 명과 신뢰를 쌓고 그들의 사정을 끝까지 챙긴다), **전략**(무엇을 맡고 무엇을 버릴지, 누구를 어디에 세울지 정한다). 서기 출신이라 무엇이든 꼼꼼히 기록하는 습관이 이 셋을 받친다
- **주인공의 디자인(외모)은 만들지 않는다.** 화면에 나오지 않는 플레이어 시점 인물이다
- **용사가 알아본 아이 (2026-10-17 사용자 확정):** 약 20년 전, 열두 살 무렵의 주인공은 마을 아이들을 모아 '모험가 놀이'를 했다. 아이마다 맞는 역할을 맡기고, 누가 어디에 설지 정하고, 놀이가 끝나면 누가 무엇을 잘했는지 적어 두었다. 여행 중 하웰에 들른 용사 에드릭이 그 모습을 보고 촌장에게 귓속말을 남겼다: "저 아이는 검은 못 들어도 사람을 쓸 줄 압니다. 언젠가 이 마을 길드에 사람이 필요해지면, 저 아이에게 맡기십시오."
- **지금:** 괴수가 돌아오자 촌장이 그 말을 떠올리고, 폐허가 된 길드의 열쇠를 주인공에게 맡긴다. 공증인 바실이 재건 서류를 처리한다. 주인공 자신은 그 놀이를 기억도 못 한다
- **플레이가 곧 단장의 재능이다.** 동료 육성, 장비 맞추기, 파티 편성, 의뢰 고르기, 전투 지휘처럼 플레이어가 하는 모든 일이 단장의 역량이고, 에드릭이 알아본 것이 바로 이것이다. 플레이어가 잘할수록 "용사의 눈이 옳았다"가 증명된다
- 주인공은 화면에 나오지 않는다 (04-game-flow.md). 전장에 서지 않고 고르고 지휘하고 기록한다는 게임 구조가 곧 이 인물이다

**시스템과의 연결**

| 단장의 무기 | 게임에서 |
|---|---|
| 길드 관리 | 길드 재건(시설·평판·자금), 매주 의뢰 고르기, 고르지 않은 의뢰의 결과 감당, **동료 육성과 장비** |
| 유대 | 호감도, 동료별 개인 이야기, 호감도 CG, 유대가 깊을수록 판정·전투에서 힘이 됨 |
| 전략 | 판정마다 내보낼 동료 고르기, 파티 구성, 전투 지휘. 기록 습관 덕에 의뢰 정보와 성공률이 보이고, 한 번 싸운 적의 약점이 다음부터 보인다 |
| (운) | 행운 주사위. 언제 쓸지가 단장의 판단 |

**장마다 깨닫는 것:** 1장 싸울 수는 없지만 적을 수는 있다 → 2장 고르는 것도 싸움이다 → 3장 동료들이 영웅이 되게 하는 게 내 일이다 → 최종장: 단장은 끝까지 용사처럼 강해지지 않는다. 대신 **용사가 하지 못한 것**(길드를 지키고, 사람을 잇고, 앞을 내다보는 것)을 해낸다. 에드릭은 누구보다 강했지만 혼자 강했고, 용사 일행이 흩어진 것도 그 때문이었는지 모른다. 그래서 그는 검이 아닌 사람을 골랐다 (가안, 용사 일행 해산의 진실과 함께 다듬는다)

**주제:** 전대에는 용사 한 명이 세상을 구했다. 이번에는 **평범한 사람들이 모인 길드**가 세상을 구한다.

**하웰 모험가 길드 (2026-10-17 바꿈: 등불 컨셉은 버렸다)**
- 길드 이름은 특별한 이름 없이 **마을 이름 + 모험가 길드**다. 변경의 작은 마을 **하웰(Harwell)**의 평범한 모험가 길드이고, **전대 용사와는 아무 관계가 없다.** 그럭저럭 활동하다가 평화의 시대에 몰락했다 (2026-10-17 사용자: 하웰 모험가 길드는 전대 용사와 관계없는 평범한 길드다)
- 그래서 이 이야기는 이름 없는 시골 길드가 용사의 전설에 닿을 만큼 자라는 이야기다. 용사와의 연결은 길드가 아니라 **주인공**(에드릭이 알아본 아이)과 **동료**(알도의 딸 리나, 용사 일행 고드릭)를 통해서다
- 문장: 파란 바탕에 **은빛 우물과 그 위로 교차한 두 검** (하웰은 오래된 우물 마을이다). 정식 문장 그림은 Claude가 그린다 (`art/refs/emblem-harwell.png`)
- **1장의 마지막:** 첫 결전 뒤 15년 만에 정문에 **길드 간판을 다시 건다.** 다음 날 아침 길드 앞에 의뢰인들이 줄을 선다
- 길드 화면은 재건 단계에 따라 바뀐다 (폐허 → 복구 1단계 → 복구 2단계 배경)
- 에드릭의 말버릇: "문은 열어 둬. 누가 두드릴지 모르니까." (검도 못 쥐는 아이를 알아본 그의 눈과 이어진다)

**미스터리:** ① 30년 평화 뒤에 괴수들은 왜 다시 날뛰나 (재앙의 흔적, 흑기사 모르칸트) ② 용사 일행은 왜 흩어졌고 에드릭은 어디로 갔나 ③ 에드릭은 어린 나에게서 정확히 무엇을 봤고, 그 귓속말에는 다른 뜻이 있었나 (그는 괴수가 돌아올 것을 알았던 걸까)

**동료 세대:** 동료들은 평화 시대에 자라 모험을 동화로만 알던 세대다. 처음 떠나는 모험이 서툴고 설레는 건 단장과 같다 (**같이 처음인 사이**). 리나는 용사 일행 알도의 딸, 고드릭은 살아남은 용사 일행이다.

**아직 정할 것:** 대륙 이름, 재앙의 이름, 용사 일행 해산 사건, 회상이 열리는 계기(04-game-flow.md 3.5), 촌장 캐릭터 (게임 제목은 「몰락한 길드 재건하기」로 확정, 0절)

### 8.1 이 세계관이 시스템과 맞물리는 지점

| 시스템 | 세계관 안에서의 모습 |
|---|---|
| 챕터 맵 / 노드 | 길드가 받은 **의뢰**. 의뢰 게시판에서 고르고 현장으로 떠난다 |
| 캠프 | **길드 하우스.** 동료와 대화하고, 호감도 이벤트가 일어나고, 장비를 정비한다. 시설을 늘리면 길드 하우스가 커진다 |
| 동료 영입 | 길드 **입단 면접/스카우트.** 본편 동료는 메인 스토리에서 합류하고, 확장팩 동료는 "특별 스카우트 의뢰"로 등장한다 |
| 동료 이탈·사망 | 길드원이 신념 차이로 **탈퇴**하거나, 의뢰 중 목숨을 잃는다 |
| 확장팩 | 길드가 **새 지역 지부**를 낸다. 지역마다 새 세력과 새 문제가 있다 |
| 주사위 스킨 | 길드 문장이나 동료 테마가 들어간 주사위. 플레이 보상으로 얻는다 |

### 8.2 "흔하다"는 약점을 보완할 차별화 훅 ❓ (하나 고르거나 섞는다)

| 훅 | 내용 | 효과 |
|---|---|---|
| **H1. 몰락한 명문 길드 재건** | 한때 왕국 최고였던 길드가 한 사건으로 몰락했다. 주인공은 이름만 남은 길드를 물려받는다. "그때 무슨 일이 있었나"가 메인 미스터리다 | 성장 서사가 선명하다. 옛 길드원이 동료/적으로 나온다 |
| **H2. 길드 간 경쟁** | 도시에 여러 길드가 있고, 의뢰를 두고 경쟁한다. 라이벌 길드의 선택이 플레이어 선택에 반응한다 | BG3식 세력 관계와 선택 결과를 보여 주기 좋다 |
| **H3. 길드의 비밀 의뢰인** | 길드에 정체불명의 후원자가 비밀 의뢰를 넣는다. 의뢰를 받을지, 의뢰인을 파헤칠지 선택한다 | 도덕적 선택(BG3식 회색 선택지)을 만들기 쉽다 |

**결정: H1 (몰락한 명문 길드 재건).** 재건 서사는 동료가 하나씩 모이는 구조와 잘 맞는다. 라이벌 길드(H2)는 확장팩용 소재로 남겨 둔다.

**세력:** 왕관(왕국과 영주), 새벽빛 교회, 금저울 상회, 회색 쥐(뒷골목)가 모두 이 길드를 주목한다. 이유는 단순하게 **다른 모험가 길드보다 빠르게 크고 있어서**다 (2026-10-17 사용자 결정). 세력은 이야기 속 조직으로 등장하며, 우호도 시스템은 두지 않는다 (v0.5, [06-factions.md](06-factions.md)).

**중세 분위기 원칙:** 기사도, 봉건 영주, 교회, 길드 조합, 문장(紋章)을 세계의 뼈대로 쓴다. 화약과 현대식 말투는 넣지 않는다. UI와 텍스트도 양피지, 필사본, 인장 같은 중세 소재로 통일한다.

### 8.3 톤 가이드

- 기본 톤은 **밝은 모험물**이다. 동료끼리의 만담과 캠프 이벤트는 서브컬처답게 가볍고 귀엽게 간다
- 의뢰 안의 선택은 **BG3처럼 무겁게** 간다. 쉬운 정답이 없는 선택을 챕터마다 1~2개 넣는다
- 밝은 일상과 무거운 선택의 낙차가 이 게임의 정서적 리듬이다

## 9. 아트 방향 (1인 개발 비용 기준)

> **결정 (2026-10-15):** 인게임 도트는 하지 않는다. 도트는 코스튬마다 모든 프레임을 다시 그려야 해서 코스튬 보상과 맞지 않고, 외주 비용도 SD Spine과 큰 차이가 없다. 인게임은 **SD 2D 컷아웃 애니메이션**, 대화는 **서브컬처 일러스트**로 간다.
> **변경 (2026-10-15): 외주 없음.** 일러스트(스탠딩, SD, 배경, CG, 아이콘)는 **Codex + 이미지 생성 모델**로 만들고, UI·이펙트·애니메이션·주사위는 Claude가 코드로 만든다. 결과물은 AI 생성물이므로 **Steam의 AI 콘텐츠 공개 의무에 따라 상점 페이지에 밝힌다.**
> 화풍: 서브컬처 애니풍 캐릭터 + 짙은 중세 분위기. UI는 중세 필사본풍. 작업 지침과 전체 목록은 [art/README.md](../art/README.md)에 있다.

| 용도 | 방식 | 비고 |
|---|---|---|
| 전투 | **SD 2D + Spine** | 공통 리그를 재사용해 캐릭터당 비용을 낮춘다. 트릭컬식 |
| 대화 | 스탠딩 일러스트 + 표정 4~6종 | 외주 |
| 궁극기 | 컷인 일러스트 1장 | 서브컬처 매력 포인트 |
| 맵 | 타일셋 기반 탑다운 | 에셋 스토어 + 수정 |
| 생성형 AI | **캐릭터 일러스트와 스토리에는 쓰지 않는다** | 코드, 툴, 내부 목업에만 쓴다 |

## 11. 개발 로드맵 (초안)

> **1차 개발 = 1~3장** (2026-10-17). M5 정식 출시의 "메인 스토리"는 3장까지를 뜻한다. 동료 서브 스토리 5단계도 3장 완료가 마지막 조건이라 이 범위 안에서 모두 볼 수 있다.
>
> **3장까지의 범위와 끝 (2026-10-17 사용자 결정)**
> - 3장 안에 **길드 재건을 모두 마칠 수 있다.** 기준: 서브 의뢰(위탁 의뢰) 약 10일치(게임 안 10주 안팎)를 돌리고 메인 스토리를 다 깨면 공사 5단계 완공이 가능하게 금화·재료 밸런스를 맞춘다
> - **본편의 마지막 장면:** 길드 명성이 높아져 **왕의 귀에까지 들어간다.** 왕은 일러스트를 간단히 만들고 **실루엣으로만** 보여 준다
> - 그 뒤 이야기(왕의 부름 이후)는 **확장팩**에서 잇는다
