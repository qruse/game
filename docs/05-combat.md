# 전투 규칙서 v0.1

> 작성일 2026-10-15 · 상태: 초안 (M0 페이퍼 프로토에서 검증할 수치는 ⚖️ 표시)
> 근거: [02-game-concept.md](02-game-concept.md) 5절, [04-game-flow.md](04-game-flow.md)
> 목표: **BG3의 판단하는 재미는 남기고, 한 판을 2~3분(3~5라운드)으로 줄인다.**

## 1. 설계 원칙

1. **모든 굴림은 d20이고, 결과 확률을 미리 보여 준다.** 운에 진 게 아니라 확률을 알고 선택한 결과가 되게 한다
2. **한 턴에 고민할 것은 "어디로 갈까 + 무엇을 할까" 두 가지뿐이다.** BG3의 보조행동, 반응 선택, 주문 슬롯은 뺀다
3. **환경을 쓰면 판이 뒤집힌다.** 불, 물, 높이, 낭떠러지를 맵마다 1~2개씩 둔다
4. **대화가 전투를 바꾼다.** 앞 칸의 판정 결과가 전투 시작 조건을 바꾼다
5. **빨리 끝낼수록 보상이 크다.** 라운드 목표 보너스로 템포를 유도한다

## 1.1 파티: 3명

- 전투에 나가는 동료는 **3명**이다 (2026-10-15 결정, 4명에서 변경)
- 이유:
  - 한 턴에 움직일 캐릭터가 적어서 **템포 목표(2~3분)에 맞는다**
  - 모바일 화면에서 7×5 맵이 덜 붐빈다
  - **조합 고민이 커진다.** 탱커·딜러·힐러를 다 챙길 수 없어서 "힐러를 뺄까, 딜러를 뺄까"가 매 의뢰의 선택이 된다
- **대화 판정도 파티 3명의 특기만 쓴다.** 누구를 데려가느냐가 열리는 선택지를 바꾼다 (실패해도 이야기는 계속되므로 진행이 막히지 않는다)
- **캠프 칸에서 파티를 바꿀 수 있다.** 영입한 동료는 모두 길드 마차로 함께 이동한다고 설정한다. 의뢰 도중에도 다음 구간에 맞춰 조합을 바꾸는 판단이 생긴다

## 2. 전투 화면

```
 가로 화면 (모바일 기준)
┌───────────────────────────────────────────────┐
│ 라운드 2   [영감 ◆◆◇]            ⏩2배속  ⚙️   │
│                                                │
│      1   2   3   4   5   6   7                 │
│  A  [  ][  ][▲ ][  ][  ][  ][  ]   ▲ 높은 곳   │
│  B  [리][  ][▲ ][  ][도][  ][  ]   ~ 기름      │
│  C  [세][  ][  ][~ ][~ ][늑][  ]   ≈ 물        │
│  D  [아][  ][  ][  ][  ][늑][궁]   ▓ 상자(엄폐) │
│  E  [  ][  ][▓ ][  ][  ][  ][  ]   ┃ 낭떠러지  │
│                                                │
│ ┌────────────────────────────────────────────┐ │
│ │[리나 HP 22/22] [기본공격][방패 강타][도발][⚡]│ │

```

- 맵은 **7열 × 5행.** 아군 3명은 왼쪽 2열, 적은 오른쪽 2~3열에서 시작한다
- 칸은 휴대폰에서 손가락으로 누르기 충분한 크기다(가로 화면 기준 칸당 약 150px)
- ⚖️ 파티가 3명이 되어 맵 여유가 생겼다. 그래도 좁으면 8×5로 넓힌다(M0에서 확인)

## 3. 능력치

### 3.1 기본 능력치 (4종)

| 능력치 | 전투에서 | 대화 판정에서 |
|---|---|---|
| 힘 | 근접 무기 명중·피해, 밀치기 저항 | 위협, 운동 |
| 민첩 | 원거리·경량 무기 명중·피해, 회피형 저항(범위 공격) | 은신, 손재주 |
| 지능 | 마법 명중·피해 | 지식, 조사, 마법학 |
| 매력 | 지원 스킬 효과, 정신계 저항(수면, 도발) | 설득, 기만, 공연 |

- 화면에는 **보정치만** 보여 준다(예: 힘 +3). D&D처럼 18 같은 원점수는 쓰지 않는다
- 1레벨 동료의 주 능력치 보정은 +3, 나머지는 -1~+2

### 3.2 파생 수치

| 수치 | 계산 | 예 (리나 1레벨) |
|---|---|---|
| **명중 보너스** | 주 능력치 보정 + 숙련(레벨 1~4: +2, 5~8: +3, 9~10: +4) | +3 + 2 = **+5** |
| **방어도(AC)** | 방어구 기본값 + 방패 + 장신구 | 사슬 갑옷 14 + 방패 2 = **16** |
| **체력(HP)** | 역할 기본값 + 레벨당 증가 | 탱커 22 |
| **이동력** | 역할별 고정 (2~4칸) | 3 |
| **저항 판정** | d20 + 해당 능력치 보정 (+숙련, 주 능력치만) | |

## 4. 턴 진행

### 4.1 진영 턴

```
[아군 턴] 아군 3명이 원하는 순서로 한 명씩 행동 → [적 턴] 적 전원이 정해진 순서로 행동 → 다음 라운드
```

- BG3처럼 캐릭터마다 이니셔티브를 굴리지 않는다. **아군 3명의 순서를 플레이어가 정한다** → 콤보를 짜는 재미, 기다림 없음
- 기습에 성공하면 적의 첫 턴이 사라진다. 반대로 기습당하면 적이 먼저 움직인다

### 4.2 캐릭터 한 명의 행동

| 단계 | 내용 |
|---|---|
| **이동** (선택) | 이동력만큼 상하좌우로 이동. 높은 곳에 오르려면 1칸 추가. 행동하기 전까지는 **되돌리기 가능** |
| **행동** (1개) | 기본 공격 / 스킬 / 궁극기 / 아이템 / 방어(AC +2, 다음 턴까지) / 상호작용(쓰러진 아군 일으키기, 상자 열기, 레버) |
| 이동 → 행동, 행동 → 이동 | 둘 다 가능하다 (치고 빠지기) |

### 4.3 자동 반응: 기회 공격

- 근접 무기를 든 캐릭터는 **인접한 적이 자기 옆 칸에서 벗어나면 자동으로 기본 공격 1회**를 한다
- 이동 경로가 기회 공격을 유발하면 이동 전에 경고를 표시한다
- 탱커가 길목을 막는 플레이가 여기서 나온다

## 5. 판정 규칙

### 5.1 공격 굴림

```
d20 + 명중 보너스 ≥ 대상 AC  →  명중
```

- **자연 20:** 대성공. 피해 주사위를 두 번 굴린다
- **자연 1:** 무조건 빗나감
- 화면 표시: 공격 대상을 누르면 `명중 70% · 피해 5~11` 처럼 보여 준다

**명중률 표 (참고)**

| 명중 보너스 \ 대상 AC | 11 | 12 | 13 | 14 | 15 | 16 |
|---|---|---|---|---|---|---|
| +4 (1레벨 적) | 70% | 65% | 60% | 55% | 50% | 45% |
| +5 (1레벨 동료) | 75% | 70% | 65% | 60% | 55% | 50% |
| +6 | 80% | 75% | 70% | 65% | 60% | 55% |

### 5.2 유리 / 불리

- **유리:** d20을 두 번 굴려 높은 값 (70% → 91%, 50% → 75%)
- **불리:** d20을 두 번 굴려 낮은 값
- 유리와 불리가 동시에 있으면 서로 지운다(일반 굴림)

| 유리해지는 경우 | 불리해지는 경우 |
|---|---|
| 높은 곳에서 낮은 곳으로 원거리 공격 | 엄폐물(상자) 뒤의 대상을 원거리 공격 |
| **협공:** 대상의 정반대 쪽(좌우 또는 상하)에 아군이 있음 | 원거리 공격자 옆에 적이 붙어 있음 |
| 은신 상태에서 공격 | 연기 속의 대상을 공격 |
| 대상이 넘어짐(근접 공격만) | 공격자가 공포·실명 상태 |

### 5.3 저항 판정 (범위 스킬, 상태이상)

```
대상이 굴림: d20 + 저항 능력치 보정 ≥ 시전자의 난이도(DC = 8 + 명중 보너스)
```

- 저항에 성공하면 상태이상을 피하고, 범위 피해는 절반만 받는다
- 화면에는 `수면 성공률 60%` 처럼 **시전자 입장의 성공 확률**로 보여 준다

### 5.4 영감 토큰 (대화와 공유)

- 대화 판정 실패, 전투 중 자연 1이 나오면 영감 +1 (최대 3)
- **영감 1개로 아군의 d20 굴림 하나를 다시 굴린다**(공격, 저항 모두). 대화와 전투가 같은 토큰을 쓴다
- 대화에서 아껴 둔 영감이 보스전의 한 방이 되는 식의 연결이 생긴다
- 영감은 돈으로 팔지 않는다

## 6. 피해와 쓰러짐

- 피해 = 무기/스킬 주사위 + 능력치 보정. 예: 롱소드 1d8+3 = 4~11
- **HP 0 = 쓰러짐(기절).** 전투 중 죽지 않는다
  - 인접한 아군이 "일으키기"(행동)를 하면 HP 1로 일어난다. 치유 스킬도 일으킨다
  - 쓰러진 채로 전투가 끝나면 **부상**(최대 HP -20%, 다음 캠프에서 회복)
- **동료의 죽음은 이야기 선택으로만 일어난다.** 전투 패배로 동료를 잃지 않는다(모바일 게임에서 영구 손실은 이탈로 이어진다)
- **패배(아군 전원 쓰러짐):** 손실 없이 그 전투를 처음부터 다시 하거나, 이전 칸으로 후퇴한다

## 7. 환경

| 지형/물체 | 효과 | 콤보 |
|---|---|---|
| **기름** ~ | 밟으면 이동 +1 소모 | **불을 붙이면 화염 지대:** 들어가거나 턴을 시작하면 1d6 피해 + 화상, 2라운드 지속 |
| **물** ≈ | 화염 지대를 끈다 | **전기를 쓰면 감전:** 물 위의 모든 유닛 1d8 피해 + 기절 1턴(저항 판정) |
| **높은 곳** ▲ | 오르는 데 이동 +1 | 원거리 공격 유리, 근접으로 아래 적을 공격할 때 명중 +1 |
| **상자** ▓ | 원거리 공격의 엄폐(불리). 공격하면 부서짐(HP 5) | 뒤에 숨어서 버티기 |
| **폭발 통** | 공격하면 폭발: 주변 1칸 2d6 피해 | 기름 지대와 연쇄 |
| **낭떠러지** ┃ | 지나갈 수 없음 | **밀치기로 떨어뜨리면 일반 적은 즉시 제거**, 보스는 큰 피해(3d6)만 받고 근처로 복귀 |

- 맵마다 환경 요소를 **1~2종만** 둔다. 많으면 화면이 복잡해지고 판단이 느려진다

### 7.1 밀치기

- 밀치기 스킬은 대상을 1~2칸 민다(저항 판정: 힘)
- 벽이나 다른 유닛에 부딪히면 둘 다 1d4 피해
- 화염 지대, 물, 낭떠러지로 밀어 넣는 것이 핵심 활용법이다

## 8. 상태이상 (8종으로 제한)

| 상태 | 효과 | 지속 |
|---|---|---|
| 화상 | 턴 시작 시 1d4 피해 | 2턴 |
| 기절 | 행동 불가 | 1턴 |
| 속박 | 이동 불가 (공격은 가능) | 1~2턴 |
| 수면 | 행동 불가, 피해를 받으면 깨어남 | 2턴 |
| 넘어짐 | 근접 공격받을 때 유리 허용, 일어나는 데 이동 절반 소모 | 다음 턴까지 |
| 도발 | 도발한 대상만 공격할 수 있음 | 1턴 |
| 축복 (버프) | 명중·저항 굴림에 +1d4 | 2턴 |
| 은신 (버프) | 다음 공격 유리, 적의 우선 표적에서 빠짐. 공격하면 해제 | 공격할 때까지 |

## 9. 궁극기

- 캐릭터마다 **결의 게이지**(0~100)가 있다
  - 행동하면 +25, 피격되면 +15, 자연 20이면 +25
  - 보통 **3라운드쯤** 처음 쓸 수 있다 → 전투 후반의 결정타
- 궁극기를 쓰면 컷인 일러스트가 1~2초 나온다(설정에서 끌 수 있음)

## 11. 적 설계

### 11.1 적 유형과 행동 방식 (AI)

| 유형 | 예 | 행동 방식 |
|---|---|---|
| 돌격형 | 도적, 해골 병사, 용병 기사 | 가장 가까운 적에게 붙는다. HP가 낮은 대상을 선호 |
| 원거리형 | 도적 궁수, 석궁병 | 높은 곳·엄폐물을 찾아 이동 후 사격. 붙으면 물러난다 |
| 야수형 | 늑대, 전투견 | **협공 위치**를 노린다. 넘어뜨리기 |
| 지원형 | 사교도 사제 | 아군 적을 강화·회복. 우선 처치 대상 |
| 방해형 | 덫사냥꾼, 암살자 | 덫 설치, 은신 후 기습 |

- 적을 누르면 이동 범위와 공격 범위를 보여 준다(위협 범위 확인)
- 적의 다음 행동을 미리 표시하지는 않는다(BG3 감성 유지). ⚖️ 너무 어려우면 "노린 대상 표시"를 추가한다

### 11.2 1장 적 수치 (1레벨 기준) ⚖️

| 적 | HP | AC | 명중 | 공격 | 특징 |
|---|---|---|---|---|---|
| 도적 | 11 | 12 | +4 | 단검 1d6+2 | — |
| 도적 궁수 | 9 | 12 | +4 | 단궁 4칸 1d8+2 | 높은 곳 선호 |
| 늑대 | 9 | 13 | +4 | 물기 1d6+2 | 명중 시 넘어뜨림 (저항: 힘) |
| 멧돼지 | 15 | 11 | +4 | 돌진 1d8+2 | 직선 3칸 돌진, 경로의 유닛 밀침 |
| 덫사냥꾼 | 10 | 12 | +4 | 손도끼 1d6+2 | 전투 시작 시 덫 2개 설치 |
| **보스: 붉은 수염** | 48 | 14 | +5 | 대도끼 1d12+4 | 아래 참고 |

**보스 붉은 수염**
- 1페이즈: 대도끼 공격, 2라운드마다 **휩쓸기**(인접한 모든 적 1d8+4)
- 2페이즈(HP 50% 이하): **분노**, 한 턴에 2회 공격. 도적 2명 증원
- 공략 포인트: 절벽 맵이라 밀치기가 통하지만 보스는 즉사하지 않는다. 기름 통을 터뜨려 증원을 막을 수 있다

### 11.3 전투 규모 기준 ⚖️

| 전투 종류 | 적 HP 합계 | 예상 길이 |
|---|---|---|
| 일반 (적 2~4명) | 40~55 | 3~4라운드 |
| 정예 (적 3~5명) | 55~70 | 4~5라운드 |
| 보스 | 보스 45~90 + 증원 | 5~6라운드 |

> 계산 근거: 1레벨 아군 3명의 라운드당 기대 피해는 조합에 따라 약 14~20, 평균 16(명중률 60~70% 기준). 딜러 위주(리나+세실+아델하이트) 18.9, 힐러 포함(리나+아델하이트+미리엄) 13.9. 첫 라운드를 이동에 쓰는 것을 감안했다. 적 도적 1명의 기대 피해는 라운드당 2.5~3.6이다(아군 AC 12~16 기준).

## 12. 승리 조건과 보상

- 기본 승리: 적 전멸. 맵에 따라 **보스 처치 / N라운드 버티기 / 탈출 / NPC 호위**로 바꾼다
- **별 3개 목표** (보너스 보상):
  - ★ 승리
  - ★ 아무도 쓰러지지 않음
  - ★ N라운드 안에 승리 (맵마다 다름, 보통 4)
- 보상: 경험치, 금화, 전리품. 별 3개면 추가 재료나 영감 +1

## 13. 대화 → 전투 연결

| 앞 칸의 결과 | 전투에 주는 효과 |
|---|---|
| 기습 성공 | 적의 첫 턴 없음 |
| 정보 획득 | 적 배치와 약점 미리 공개 |
| 설득 성공 | 적 일부가 싸우지 않고 떠남 |
| 함정 발견 | 덫 위치 공개 |
| 판정 실패 (들킴) | 적 증원 1~2명, 또는 아군이 기습당함 |
| 선택 결과 | 다른 세력이 아군 편으로 참전 (NPC 원군) |

## 14. 성장

- 레벨 1~10 (메인 스토리 기준)
- 레벨업: HP 증가, 5레벨과 9레벨에 숙련 +1
- **3·6·9레벨: 강화 선택** — 스킬마다 강화 2개 중 1개를 고른다
  - 예: 방패 강타 → "밀치기 2칸" 또는 "기절 1턴 추가"
  - BG3의 특기 선택처럼 같은 캐릭터도 다르게 키울 수 있다
- 장비 3칸: 무기 / 방어구 / 장신구

## 15. 템포 장치

| 장치 | 내용 |
|---|---|
| 2배속 | 이동, 연출 모두 2배 |
| 적 턴 빨리 감기 | 적 턴을 한 번에 진행 |
| 주사위 연출 생략 | 설정에서 끌 수 있다 (결과 숫자만 표시) |
| 이동 되돌리기 | 행동하기 전까지 자유롭게 |
| 자동 전투 | 별 3개로 클리어한 전투에서만 사용 가능 |
| 컷인 생략 | 같은 궁극기를 두 번째 볼 때부터 짧게 |

## 16. 조작 흐름 (모바일)

```
아군 탭 → 이동 범위(파랑) + 공격 가능 범위(빨강) 표시
→ 칸 탭: 이동 (되돌리기 버튼 표시)
→ 행동 버튼 탭: [기본 공격][스킬1][스킬2][궁극기][방어][기타]
→ 대상 칸들이 강조되고 각각 "명중 70% · 피해 5~11" 표시
→ 대상 탭 → 확인 탭 → 주사위 굴림(0.5초) → 결과
```

- PC(Steam)는 같은 흐름을 마우스로 하고, 단축키(1~4 스킬, Space 턴 종료)를 추가한다

## 17. M0 페이퍼 프로토에서 검증할 것

1. 일반 전투가 정말 3~4라운드, 2~3분에 끝나는가 (3인 파티 기준)
1-1. 힐러 없는 조합으로도 보스를 깰 수 있는가 (조합 자유도)
2. 7×5 맵이 너무 좁지 않은가 (이동력 2~4칸 기준)
3. 적 행동 미리보기 없이도 억울하지 않은가
4. 결의 게이지로 궁극기가 3라운드쯤 나오는가
5. 영감 공유가 대화와 전투를 이어 주는 느낌이 드는가
6. 환경 콤보가 실제로 자주 쓰이는가 (맵 3개 중 2개 이상에서)
