## 0. 2026-10-16 전환: 판정 칸 전투 (포 더 킹식)

칸 이동 전투(아래 1~17절)가 모바일에서 무겁고 일러스트가 작게 보여서, **사이드뷰 대치 + 판정 칸** 방식으로 바꿔 시험 중이다. 1~17절은 수치·스킬 아이디어 참고용으로 남긴다.

| 항목 | 규칙 |
|---|---|
| 화면 | 배경 위에 동료 3명(왼쪽)과 적(오른쪽)이 마주 선다. 칸 이동 없음 |
| 순서 | 라운드마다 속도 순으로 한 명씩 행동. 위쪽 줄에 차례 표시 |
| 조작 | 무대에서 대상을 눌러 두고, 행동 버튼을 누르면 바로 굴린다. 버튼에 그 대상 기준 칸마다 성공 확률 |
| 판정 칸 | 행동마다 칸 1~3개. **칸마다 d20 + 능력치 ≥ 난이도**면 성공 (주사위로 성공·실패를 정하는 원칙 유지). 성공한 칸 비율만큼 피해·회복, 전부 성공하면 완벽 성공 보너스(기절 등) |
| 난이도 | 적을 치면 그 적의 방어(방어 자세 +3, 연막 +3, 엄폐 +4), 혼자 하는 행동은 10, 환경 행동은 오브젝트마다 정해진 값 |
| 행운 주사위 | 파티 공용 최대 3개 (2026-10-16 "운명 주사위"에서 이름 바꿈). 굴리기 전에 칸 하나를 확정 성공으로 바꾼다. 20이 나오면 1개 돌려받음 |
| 주변 환경 | 전투마다 오브젝트 3~4개. **행동 목록에 나오지 않고 이름도 숨겨져 있다.** 플레이어가 무대에서 직접 눌러 찾아야 이름과 쓸 방법이 드러난다(쉬워지지 않게). **동료마다 쓸 수 있는 범위가 다르다**: 리나(힘) 고목 쓰러뜨리기·방책 부수기·술통 굴리기·탁자 엎기, 세실(민첩) 항아리 던지기·덤불 숨기·샹들리에 밧줄 끊기, 아델하이트(지능·불) 불꽃 화살로 항아리·방책·술통에 불붙이기·마력탄으로 밧줄 끊기, 미리엄 덤불·탁자 뒤에 숨기. 맞는 동료가 없으면 "지금 동료로는 쓸 방법이 안 보인다" |
| 궁극기 | 결의 100%면 판정 없이 발동, 컷인. 결의는 행동마다 +15, 성공 칸마다 +8, 맞으면 +12 (약 3턴에 한 번) |
| 쓰러짐 | 동료는 HP 0이면 쓰러짐(치유로 일으킴). 전원 쓰러지면 패배 |

- 프로토타입: `godot/scripts/fk_*.gd` (메인 장면 `fk.tscn`). 수치는 `fk_defs.gd`
- 자동 시뮬레이션 300판 (2026-10-16): 숲속 공터 평균 3라운드·승률 100%, 무너진 길드 회관(보스) 평균 6라운드·승률 83~95%

### 0.1 2026-10-17 전투 검증 뒤 바꾼 것

검증에서 나온 문제: 적이 누구를 칠지 몰라 판단할 거리가 적었다, 치유 동료가 없으면 쓰러진 동료를 살릴 길이 없었다, 의뢰 세 개가 같은 전투를 돌려 썼다, 너무 쉬웠다.

| 항목 | 규칙 |
|---|---|
| 적의 노림 | 라운드가 시작될 때 적마다 칠 대상을 정하고 머리 위에 "▶ 이름"으로 보여 준다. 보스는 세 번째 행동마다 "▶ 동료 전원"(휩쓸기). 동료 이름 아래에는 "노림 N". 도발·은신·쓰러짐이 생기면 노림을 다시 정한다. 체력이 가장 낮은 동료를 노리는 비율 40% |
| 회복약 | 잡화점에서 산 회복약을 전투에서 쓴다. 행동 한 번, 판정 없이 체력 10, **쓰러진 동료도 일으킨다** |
| 성장 반영 | 레벨·장비가 체력·방어·스킬 위력에 붙는다 (04-game-flow.md 9.2~9.3절). 주방 도시락은 그 의뢰 전투에서 동료 체력 +4/+8 |
| 새 전투 | **도적 야영지**(도적 3·궁수 2, 탁자·기름 항아리·술통), **어두운 숲**(늑대 2·덫사냥꾼, 3라운드 끝에 덫사냥꾼이 살아 있으면 늑대 증원). 새 적: 덫사냥꾼, 멧돼지(아직 안 씀) |
| 적 수치 | 도적 체력 18·위력 8, 궁수 13·8, 늑대 14·7, 붉은 수염 85·12 |
| 자동 동료 | 리나는 노림이 몰리면 도발, 세실은 자기가 노림 2 이상이면 연막, 쓰러진 동료가 있으면 회복약 |

자동 시뮬레이션 400판 (`godot/sims/battle_sim.tscn`, 회복약 1개, 동료 자동 행동):

| 전투 | 1레벨 맨몸 | 2레벨·철 무기 | 3레벨·철 무기+1·철 갑옷 |
|---|---|---|---|
| 숲속 공터 | 99% · 3.5라운드 · 아슬아슬 33% | 100% · 28% | 100% · 10% |
| 무너진 길드 회관 (보스) | 86% · 6.5라운드 · 아슬아슬 66% | 98% · 55% | 100% · 33% |
| 도적 야영지 | 99% · 3.1라운드 · 아슬아슬 41% | 100% · 39% | 100% · 20% |
| 어두운 숲 | 100% · 4.1라운드 · 아슬아슬 46% | 100% · 18% | 100% · 9% |
| 마을 어귀 (멧돼지 2·늑대 2, 3라운드 끝 멧돼지 증원) | 67% · 5.9라운드 · 아슬아슬 76% | 94% · 49% | 100% · 32% |
| 도적 천막촌 (도적 2·궁수 2·덫사냥꾼, 경보 증원) | 99% · 3.1라운드 · 아슬아슬 49% | 100% · 49% | 100% · 25% |

## 1. 설계 원칙

1. **모든 굴림은 d20이고, 결과 확률을 미리 보여 준다.** 운에 진 게 아니라 확률을 알고 선택한 결과가 되게 한다
2. **한 턴에 고민할 것은 "어디로 갈까 + 무엇을 할까" 두 가지뿐이다.** BG3의 보조행동, 반응 선택, 주문 슬롯은 뺀다
3. **환경을 쓰면 판이 뒤집힌다.** 불, 물, 높이, 낭떠러지를 맵마다 1~2개씩 둔다
4. **대화가 전투를 바꾼다.** 앞 칸의 판정 결과가 전투 시작 조건을 바꾼다
5. **늦어지면 전장에 사건이 터진다.** 점수 대신 맵마다 정해진 라운드의 사건(증원, 도주 등)으로 템포를 유도한다 (12.2절)
6. **어떻게 이겼는지가 기록된다.** 별점 대신 "전설 장면"이 연대기와 소문으로 남는다 (12.1절)

## 1.1 파티: 3명

- 전투에 나가는 동료는 **3명**이다 (2026-10-15 결정, 4명에서 변경)
- 이유:
  - 한 턴에 움직일 캐릭터가 적어서 **템포 목표(2~3분)에 맞는다**
  - 모바일 화면에서 7×5 맵이 덜 붐빈다
  - **조합 고민이 커진다.** 탱커·딜러·힐러를 다 챙길 수 없어서 "힐러를 뺄까, 딜러를 뺄까"가 매 의뢰의 선택이 된다
- **대화 판정도 파티 3명의 특기만 쓴다.** 누구를 데려가느냐가 열리는 선택지를 바꾼다 (실패해도 이야기는 계속되므로 진행이 막히지 않는다)
- **캠프 칸에서 파티를 바꿀 수 있다.** 영입한 동료는 모두 길드 마차로 함께 이동한다고 설정한다. 의뢰 도중에도 다음 구간에 맞춰 조합을 바꾸는 판단이 생긴다

```

│                                                │
│      1   2   3   4   5   6   7                 │
│  A  [  ][  ][▲ ][  ][  ][  ][  ]   ▲ 높은 곳   │
│  B  [리][  ][▲ ][  ][도][  ][  ]   ~ 기름      │
│  C  [세][  ][  ][~ ][~ ][늑][  ]   ≈ 물        │
│  D  [아][  ][  ][  ][  ][늑][궁]   ▓ 상자(엄폐) │
│  E  [  ][  ][▓ ][  ][  ][  ][  ]   ┃ 낭떠러지  │
│                                                │

```

- 위 그림은 기본 크기(7×5) 예시다. **맵 크기는 맵마다 다르다** (2.1절)
- 아군 3명은 왼쪽, 적은 오른쪽에서 시작하는 것이 기본이다. 매복·포위 맵은 배치를 바꾼다

### 2.1 맵 크기 (맵마다 다름)

| 맵 유형 | 크기 (열×행) | 전투 감각 | 유리한 동료 |
|---|---|---|---|
| 좁은 곳 (매복, 골목) | 5×4 | 서로 붙어서 싸우는 근접전 | 리나, 이졸데 |
| 기본 | 7×5 | 균형 | — |
| 넓은 곳 (평원, 광장, 홀) | 9×5 | 이동력 차이가 크게 느껴지는 기동전 | 세실, 카샤 |
| 길쭉한 곳 (다리, 성벽, 복도) | 8×3 ~ 8×4 | 한 줄로 밀고 밀리는 밀치기 싸움 | 리나(밀치기·철벽) |
| 보스전 | 8×6 | 넓고 환경 요소가 많다 | — |

- **최대 9×6.** 화면을 끌어서 옮기지 않고 한 화면에 다 보여야 한다(템포와 전체 상황 파악)
- 칸 크기는 맵 크기에 맞춰 자동으로 바뀐다. 가장 큰 맵(9×6)에서도 휴대폰 가로 화면 기준 칸당 약 130px 이상을 유지한다
- 같은 크기라도 **못 가는 칸**(벽, 구덩이, 기둥)으로 모양을 바꾼다 (7절)

## 3. 능력치

### 3.1 기본 능력치 (4종)

| 능력치 | 전투에서 | 대화 판정에서 |
|---|---|---|
| 힘 | 근접 무기 명중·피해, 밀치기 저항 | 위협, 운동 |
| 민첩 | 원거리·경량 무기 명중·피해, 회피형 저항(범위 공격) | 은신, 손재주 |
| 지능 | 마법 명중·피해 | 지식, 조사, 마법학 |
| 매력 | 지원 스킬 효과, 정신계 저항(수면, 도발) | 설득, 기만, 공연 |

- 화면에는 **보정치만** 보여 준다(예: 힘 +3). D&D처럼 18 같은 원점수는 쓰지 않는다
- 1레벨 동료의 주 능력치 보정은 +3, 나머지는 -1~+2

### 3.2 파생 수치

> 이 문서의 AC, DC는 설계용 약어다. 화면에는 **방어, 난이도**로 쓴다. 용어 전체는 [07-originality.md](07-originality.md) 2절

| 수치 | 계산 | 예 (리나 1레벨) |
|---|---|---|
| **명중 보너스** | 주 능력치 보정 + 숙련(레벨 1~4: +2, 5~8: +3, 9~10: +4) | +3 + 2 = **+5** |
| **방어도(AC)** | 방어구 기본값 + 방패 + 장신구 | 사슬 갑옷 14 + 방패 2 = **16** |
| **체력(HP)** | 역할 기본값 + 레벨당 증가 | 탱커 22 |
| **이동력** | **캐릭터별 고정 (2~5칸)** + 이동 특성 (3.3절) | 3 |
| **저항 판정** | d20 + 해당 능력치 보정 (+숙련, 주 능력치만) | |

### 3.3 이동력과 이동 특성

캐릭터마다 **이동 칸 수**와 **이동 방식**이 다르다. 숫자만 다르면 차이가 잘 느껴지지 않으므로, 캐릭터 성격에 맞는 이동 특성을 하나씩 준다.

| 동료 | 이동력 | 이동 특성 | 플레이 감각 |
|---|---|---|---|
| 세실 | **5** | **빠져나가기:** 이동할 때 빈틈 공격을 받지 않는다 | 적진을 뚫고 들어가 후열을 노린다 |
| 이졸데 | 4 | **돌진:** 일직선으로 2칸 이상 이동한 뒤 근접 공격하면 피해 +1d4 | 거리를 벌렸다가 찌르고 들어간다 |
| 카샤 | 4 | **산악 사냥꾼:** 높은 곳에 오를 때 추가 이동 소모가 없다 | 고지대를 먼저 차지한다 |
| 로웬 | 4 | **춤추는 발걸음:** 이동력을 행동 전후로 나눠 쓸 수 있다 (예: 2칸 이동 → 노래 → 2칸 이동) | 치고 빠지기 |
| 리나 | 3 | **철벽:** 밀치기와 넘어짐에 걸리지 않는다 | 길목을 막고 버틴다 |
| 미리엄 | 3 | **인도:** 이동 대신 인접한 아군과 자리를 바꿀 수 있다 | 위험한 동료를 빼내고 대신 선다 |
| 아델하이트 | 2 | 없음 (대신 사거리 4칸) | 자리를 신중하게 잡아야 한다 |

- 이동력 차이 때문에 **누가 먼저 움직일지**가 중요해진다(빠른 캐릭터로 길을 열고, 느린 캐릭터가 따라간다)
- 7×5 맵에서 세실의 5칸은 첫 턴에 적 후열에 닿을 수 있는 거리다. ⚖️ 너무 강하면 4칸 + 특성 유지로 조정한다

## 4. 턴 진행

### 4.1 진영 턴

```
[아군 턴] 아군 3명이 원하는 순서로 한 명씩 행동 → [적 턴] 적 전원이 정해진 순서로 행동 → 다음 라운드
```

- BG3처럼 캐릭터마다 이니셔티브를 굴리지 않는다. **아군 3명의 순서를 플레이어가 정한다** → 콤보를 짜는 재미, 기다림 없음
- 기습에 성공하면 적의 첫 턴이 사라진다. 반대로 기습당하면 적이 먼저 움직인다

### 4.2 캐릭터 한 명의 행동

| 단계 | 내용 |
|---|---|
| **이동** (선택) | 이동력만큼 상하좌우로 이동. 높은 곳에 오르려면 1칸 추가. 행동하기 전까지는 **되돌리기 가능** |
| **행동** (1개) | 기본 공격 / 스킬 / 궁극기 / 아이템 / 방어(AC +2, 다음 턴까지) / 상호작용(쓰러진 아군 일으키기, 상자 열기, 레버) |
| 이동 → 행동, 행동 → 이동 | 둘 다 가능하다 (치고 빠지기) |

### 4.3 자동 반응: 빈틈 공격

- 근접 무기를 든 캐릭터는 **인접한 적이 자기 옆 칸에서 벗어나면 자동으로 기본 공격 1회**를 한다
- 이동 경로가 빈틈 공격을 유발하면 이동 전에 경고를 표시한다
- 탱커가 길목을 막는 플레이가 여기서 나온다

## 5. 판정 규칙

### 5.1 공격 굴림

```
d20 + 명중 보너스 ≥ 대상 AC  →  명중
```

- **자연 20:** 대성공. 피해 주사위를 두 번 굴린다
- **자연 1:** 무조건 빗나감
- 화면 표시: 공격 대상을 누르면 `명중 70% · 피해 5~11` 처럼 보여 준다

**명중률 표 (참고)**

| 명중 보너스 \ 대상 AC | 11 | 12 | 13 | 14 | 15 | 16 |
|---|---|---|---|---|---|---|
| +4 (1레벨 적) | 70% | 65% | 60% | 55% | 50% | 45% |
| +5 (1레벨 동료) | 75% | 70% | 65% | 60% | 55% | 50% |
| +6 | 80% | 75% | 70% | 65% | 60% | 55% |

### 5.2 유리 / 불리

- **유리:** d20을 두 번 굴려 높은 값 (70% → 91%, 50% → 75%)
- **불리:** d20을 두 번 굴려 낮은 값
- 유리와 불리가 동시에 있으면 서로 지운다(일반 굴림)

| 유리해지는 경우 | 불리해지는 경우 |
|---|---|
| 높은 곳에서 낮은 곳으로 원거리 공격 | 엄폐물(상자) 뒤의 대상을 원거리 공격 |
| **협공:** 대상의 정반대 쪽(좌우 또는 상하)에 아군이 있음 | 원거리 공격자 옆에 적이 붙어 있음 |
| 은신 상태에서 공격 | 연기 속의 대상을 공격 |
| 대상이 넘어짐(근접 공격만) | 공격자가 공포·실명 상태 |

### 5.3 저항 판정 (범위 스킬, 상태이상)

```
대상이 굴림: d20 + 저항 능력치 보정 ≥ 시전자의 난이도(DC = 8 + 명중 보너스)
```

- 저항에 성공하면 상태이상을 피하고, 범위 피해는 절반만 받는다
- 화면에는 `수면 성공률 60%` 처럼 **시전자 입장의 성공 확률**로 보여 준다

### 5.4 행운 주사위 (영감 토큰을 대체)

> 이 게임의 핵심 장치다. 운에 맡기던 d20을 **플레이어가 미리 손에 쥐고 배치하는 자원**으로 바꾼다. (참고: Citizen Sleeper의 주사위 배치)

**얻는 법**
- 의뢰를 출발할 때 d20 **2개**를 굴려 손에 든다 (행운 주사위 트레이)
- 🔥 캠프 칸에서 1개를 더 굴린다
- 아군의 굴림에서 **자연 1이 나오면 1개를 새로 굴려 얻는다** (불운 보정)
- **최대 보유 3개.** 이미 3개면 새로 얻을 때 하나를 골라 버린다. 의뢰가 끝나면 남은 주사위는 사라진다(다음 의뢰는 새로 2개)

**쓰는 법: 높은 눈은 우리에게, 낮은 눈은 적에게**

| 쓰는 곳 | 방법 | 좋은 눈 |
|---|---|---|
| **아군의 굴림** (대화 판정, 공격, 저항) | 굴리는 대신 행운 주사위를 놓는다. 그 눈이 결과가 된다 | **높은 눈** (17~20) |
| **적의 굴림** (공격, 저항) | 내 턴에 적 하나에게 **운명 낙인**을 찍는다. 그 적의 **다음 d20**이 그 눈으로 정해진다 | **낮은 눈** (1~5) |

- 놓은 20은 자연 20(대성공), 적에게 찍은 1은 자연 1(무조건 실패)로 친다
- 행운 주사위를 놓은 굴림에는 유리/불리를 적용하지 않는다
- **애매한 중간 눈(8~13)이 고민거리다.** 지금 평범한 판정에 써 버릴지, 들고 있을지
- 화면에는 놓기 전에 결과를 보여 준다: `행운 주사위 17 → 명중 확정 · 피해 5~11`

**만드는 고민**
- "18이 나왔다. 지금 설득에 쓸까, 보스전까지 아낄까?"
- "2가 나왔다. 보스의 휩쓸기에 낙인을 찍어 두면 한 번은 확실히 막는다"
- 대화와 전투가 같은 주사위를 쓰므로, **페이지 전체를 내다보는 운영**이 생긴다

**동료와 행운 주사위** ⚖️
| 동료 | 효과 |
|---|---|
| 로웬 | **운명 비틀기:** 행운 주사위 하나의 눈을 ±2 바꾼다 (의뢰당 1회) |
| 미리엄 | **기도:** 캠프에서 행운 주사위를 1개가 아니라 2개 굴린다 |

**원칙**
- 행운 주사위, 재굴림, 주사위 눈 조작은 **팔지 않는다** (게임 안 결제 없음)
- 주사위 **스킨**(겉모습)만 판매한다. 이 게임에서 주사위를 가장 많이 보게 되므로 스킨의 가치가 커진다
- 출발 2개 / 최대 3개로 확정 (2026-10-15). ⚖️ 그래도 강하면 캠프 추가를 없앤다, 약하면 출발 3개로 되돌린다

## 6. 피해와 쓰러짐

- 피해 = 무기/스킬 주사위 + 능력치 보정. 예: 롱소드 1d8+3 = 4~11
- **HP 0 = 쓰러짐(기절).** 전투 중 죽지 않는다
  - 인접한 아군이 "일으키기"(행동)를 하면 HP 1로 일어난다. 치유 스킬도 일으킨다
  - 쓰러진 채로 전투가 끝나면 **부상**(최대 HP -20%, 다음 캠프에서 회복)
- **동료의 죽음은 이야기 선택으로만 일어난다.** 전투 패배로 동료를 잃지 않는다(모바일 게임에서 영구 손실은 이탈로 이어진다)
- **패배(아군 전원 쓰러짐):** 손실 없이 그 전투를 처음부터 다시 하거나, 이전 칸으로 후퇴한다

## 7. 타일 종류

타일은 세 가지로 나뉜다.

- **바닥:** 밟고 설 수 있다. 이동 비용이나 효과가 다르다
- **물체:** 칸을 차지한다. 부수거나 터뜨릴 수 있다
- **경계:** 지나갈 수 없다

### 7.1 공통 타일 (모든 챕터)

| 구분 | 타일 | 기호 | 효과 | 콤보 |
|---|---|---|---|---|
| 바닥 | 평지 | `.` | 효과 없음 | — |
| 바닥 | **험지** (진흙, 자갈) | `,` | 들어갈 때 이동 +1 | 느린 캐릭터는 더 고생한다 |
| 바닥 | **높은 곳** | `^` | 오를 때 이동 +1 | 원거리 공격 유리, 아래 적에게 근접 명중 +1 |
| 바닥 | **덤불** | `"` | 안에 서 있으면 원거리 공격받을 때 불리 | 불이 붙으면 화염 지대가 된다. 세실은 덤불에서 바로 **은신**할 수 있다 |
| 바닥 | **기름** | `~` | 들어갈 때 이동 +1 | **불을 붙이면 화염 지대** |
| 바닥 | **얕은 물** | `=` | 들어갈 때 이동 +1. 화염 지대를 끈다 | **전기를 쓰면 감전:** 물 위 모든 유닛 1d8 + 기절 1턴(저항) |
| 바닥 | 화염 지대 (일시) | `*` | 들어가거나 턴을 시작하면 1d6 + 화상. 2라운드 뒤 사라짐 | 기름·덤불에서 생긴다 |
| 바닥 | **숨은 함정** | `t` | 밟으면 1d6 + 속박. 탐지 전엔 보이지 않는다 | 세실은 시작 시 근처 함정을 본다. 적을 밀어 넣을 수 있다 |
| 물체 | **엄폐물** (상자, 수레) | `#` | 칸을 막는다. 그 뒤를 노린 원거리 공격은 불리. HP 5, 부서진다 | 뒤에 숨어 버티기 |
| 물체 | **기름 항아리** | `o` | 공격하거나 불이 닿으면 깨지며 주변 1칸에 기름 + 불 | 연쇄 화재 |
| 경계 | 벽, 기둥 | `X` | 지나갈 수 없음. 시야는 막지 않음(단순화) | 밀쳐서 부딪히면 1d4 |
| 경계 | **낭떠러지** | `v` | 지나갈 수 없음 | **밀어서 떨어뜨리면 일반 적 즉시 제거.** 보스는 3d6만 받고 근처로 복귀 |

> 화약은 쓰지 않는다(중세 분위기). 폭발 역할은 기름 항아리가 맡는다.

### 7.2 챕터별 특수 타일

챕터마다 그 지역다운 타일을 1~2개 더한다. 새 지역에 가면 새 퍼즐이 생긴다.

| 챕터 | 지역 | 특수 타일 | 효과 |
|---|---|---|---|
| 1장 | 변경의 숲과 마을 | **건초 더미** (물체) | 기름 항아리처럼 불이 붙지만 폭발은 없다. 대신 2칸까지 번진다 |
| 2장 | 수도원과 지하묘지 | **성수 웅덩이** (바닥) | 언데드가 들어가면 1d8. 아군이 서 있으면 저항 굴림 +2 |
| 2장 | | **석관** (물체) | 엄폐물. 부수면 해골 병사가 깨어날 수 있다 |
| 3장 | 영주의 도시와 성 | **성문·레버** (물체) | 레버를 당기면(상호작용) 문이 열리거나 닫힌다. 길을 막아 적을 갈라놓는다 |
| 3장 | | **종탑 높은 곳** (바닥) | 높은 곳 효과 + 카샤의 사거리 +1 |
| 회상 | 과거의 길드 | 해당 회상 장소의 타일 | — |

### 7.3 맵 설계 원칙

- **맵 하나에 콤보 타일은 1~2종만** 둔다. 많으면 화면이 복잡해지고 판단이 느려진다
- 콤보 타일은 **적 쪽에 가깝게** 둔다. 아군이 "써먹으러 가는" 위치여야 한다
- 낭떠러지와 물은 **맵 가장자리**에 둔다. 배경 그림의 가장자리 요소와 맞춘다

### 7.4 맵 데이터 형식

맵은 텍스트로 정의한다. 배경 그림과 칸 위치를 맞추는 기준이 되고, AI와 함께 고치기도 쉽다.

```
# bt_ch1_bandit_cliff · 8x6 · 보스전
v v v v v v v v
. . " . ^ ^ . .
A . " . . o . E
A . . , . . . B
A . # . . ~ ~ E
. . # . . ~ ~ .
```

- `A` 아군 시작 칸, `E` 적 시작 칸, `B` 보스 시작 칸
- 챕터 타일 기호: `h` 건초 더미 (2장·3장 기호는 그 챕터를 만들 때 정한다)
- 머리 줄 아래에 설정 줄을 둔다: `enemies: archer bandit` (E 칸에 읽는 순서대로 배치), `boss: redbeard`, `rumor: 소문 한 줄`, `legend: 종류 | 문장`, `event: 라운드 | 종류 | 대상 | 증원 | 문장` (12절)
- 실제 파일: `godot/maps/*.txt` (전투 프로토타입이 그대로 읽는다)
- 이 예시에서는 위쪽 가장자리 전체가 낭떠러지다. 보스를 위로 밀어붙이는 것이 공략 포인트다

### 7.5 밀치기

- 밀치기 스킬은 대상을 1~2칸 민다(저항 판정: 힘)
- 벽이나 다른 유닛에 부딪히면 둘 다 1d4 피해
- 화염 지대, 물, 낭떠러지로 밀어 넣는 것이 핵심 활용법이다

## 9. 궁극기

- 캐릭터마다 **결의 게이지**(0~100)가 있다

  - 보통 **3라운드쯤** 처음 쓸 수 있다 → 전투 후반의 결정타
- 궁극기를 쓰면 컷인 일러스트가 1~2초 나온다(설정에서 끌 수 있음)

## 11. 적 설계

### 11.1 적 유형과 행동 방식 (AI)

| 유형 | 예 | 행동 방식 |
|---|---|---|
| 돌격형 | 도적, 해골 병사, 용병 기사 | 가장 가까운 적에게 붙는다. HP가 낮은 대상을 선호 |
| 원거리형 | 도적 궁수, 석궁병 | 높은 곳·엄폐물을 찾아 이동 후 사격. 붙으면 물러난다 |
| 야수형 | 늑대, 전투견 | **협공 위치**를 노린다. 넘어뜨리기 |
| 지원형 | 사교도 사제 | 아군 적을 강화·회복. 우선 처치 대상 |

- 적의 다음 행동을 미리 표시하지는 않는다(BG3 감성 유지). ⚖️ 너무 어려우면 "노린 대상 표시"를 추가한다

## 12. 승리 조건과 보상

- 기본 승리: 적 전멸. 맵에 따라 **보스 처치 / N라운드 버티기 / 탈출 / NPC 호위**로 바꾼다
- 보상: 경험치, 금화, 전리품
- **별점은 없다** (2026-10-15 결정). 흔한 숫자 채점 대신 아래 두 장치를 쓴다

### 12.1 전설 장면과 소문

- 전투마다 **"전설로 남을 장면"이 1~3개** 숨어 있다. 어떻게 이겼는지를 본다
- **힌트는 소문으로 준다.** 의뢰를 시작하거나 전투에 들어갈 때 의뢰인·동료가 한 줄 흘린다 ("붉은 수염은 기름 항아리를 끼고 산다더군…")
- **달성하면:**
  - 연대기 페이지에 금박 장면 그림과 문장이 들어간다 ("단장의 일행은 붉은 수염을 그의 기름으로 태웠다"). 여백 그림 시스템을 그대로 쓴다
  - **소문이 퍼져 세상이 반응한다.** 예: "절벽의 악마들" 소문 → 다음 도적 전투에서 겁먹은 도적 일부가 싸우기 전에 도망친다. 숫자 보상보다 이것이 핵심 보상이다
  - 그 전투에서 처음 달성한 장면 하나당 행운 주사위 1개 (이번 의뢰 안에서, 최대 보유 3개 규칙은 그대로)
- 장면은 **환경 콤보, 밀치기, 특정 동료의 특기를 써 보게 만드는 것**으로 고른다. 설계 원칙 3번과 맞물린다

| 맵 (1장) | 전설 장면 | 소문 (힌트) |
|---|---|---|
| 숲속 매복 5×4 | 포위된 채로 아무도 쓰러지지 않고 이긴다 | "매복당하고도 버틴 자들은 오래 기억되지" |
| 숲속 공터 7×5 | 불 한 번으로 적 2명 이상을 휩쓴다 / 궁수가 나팔을 불기 전에 쓰러뜨린다 | "저 숲은 바짝 말라 있어. 불씨 하나면 끝장이지" |
| 마을 외곽 9×5 | 늑대를 2라운드 안에 모두 쓰러뜨린다 | "늑대부터 잡아야 해. 우두머리가 울면 무리가 몰려와" |
| 도적 절벽 8×6 | 붉은 수염을 불길로 태운다 / 도적을 절벽 아래로 떨어뜨린다 | "붉은 수염은 기름 항아리를 끼고 산다더군" |

### 12.2 라운드 사건 (시간 압박)

- "N라운드 안에 승리" 같은 숫자 목표 대신, **맵마다 정해진 라운드에 전장에서 사건이 터진다**
- 사건은 **미리 알려 주고**(화면 위쪽에 "3라운드 끝: 궁수가 나팔을 분다"), **막을 방법**이 있다(그 적을 먼저 쓰러뜨리기 등)
- 예:
  - 숲속 공터: 3라운드가 끝날 때 궁수가 살아 있으면 나팔을 불어 도적 2명 증원
  - 마을 외곽: 3라운드가 끝날 때 늑대가 남아 있으면 우두머리가 울어 늑대 2마리 증원
  - 도적 절벽: 보스 2페이즈 증원이 이 역할을 한다
- 모든 맵에 넣지는 않는다. 좁은 매복 맵처럼 이미 긴박한 맵은 사건 없이 간다

## 14. 성장

## 15. 템포 장치

| 장치 | 내용 |
|---|---|
| 2배속 | 이동, 연출 모두 2배 |
| 적 턴 빨리 감기 | 적 턴을 한 번에 진행 |
| 주사위 연출 생략 | 설정에서 끌 수 있다 (결과 숫자만 표시) |
| 이동 되돌리기 | 행동하기 전까지 자유롭게 |
| **전투 건너뛰기** | **한 번 이긴 전투는 조건 없이 건너뛸 수 있다** (다회차 포함). 다시 하는 사람과 이야기만 보고 싶은 사람을 위한 기능이다. 바로 승리 처리, 보상은 똑같이 받는다. 행운 주사위는 쓰지도 얻지도 않고, 전설 장면은 달성되지 않는다 |
| 컷인 생략 | 같은 궁극기를 두 번째 볼 때부터 짧게 |

- **자동 전투는 넣지 않는다** (2026-10-15 결정). 반복 사냥 구조가 없고, 전투가 2~3분으로 짧으며, 행운 주사위 배치와 환경 콤보 같은 판단이 이 게임의 재미이기 때문이다. 남에게 맡길 만한 아군 AI를 만드는 비용도 아낀다
- 반복의 지루함은 위의 **전투 건너뛰기**로 해결한다
- 난이도 단계(예: 이야기 / 보통 / 어려움)는 아직 정하지 않았다

## 16. 조작 흐름 (모바일)

```
아군 탭 → 이동 범위(파랑) + 공격 가능 범위(빨강) 표시
→ 칸 탭: 이동 (되돌리기 버튼 표시)
→ 행동 버튼 탭: [기본 공격][스킬1][스킬2][궁극기][방어][기타]
→ 대상 칸들이 강조되고 각각 "명중 70% · 피해 5~11" 표시
→ 대상 탭 → (선택) 위쪽 트레이의 행운 주사위를 끌어다 놓기 → 확인 탭 → 주사위 굴림(0.5초) → 결과

운명 낙인: 트레이의 주사위를 적에게 끌어다 놓는다 (행동을 쓰지 않는 무료 조작, 턴당 1회)
```

- PC(Steam)는 같은 흐름을 마우스로 하고, 단축키(1~4 스킬, Space 턴 종료)를 추가한다

## 17. M0 페이퍼 프로토에서 검증할 것

1. 일반 전투가 정말 3~4라운드, 2~3분에 끝나는가 (3인 파티 기준)
1-1. 힐러 없는 조합으로도 보스를 깰 수 있는가 (조합 자유도)
2. 맵 크기별(5×4, 7×5, 9×5, 8×3)로 전투 감각이 실제로 다르게 느껴지는가, 9×6에서도 칸을 누르기 편한가
3. 적 행동 미리보기 없이도 억울하지 않은가
4. 결의 게이지로 궁극기가 3라운드쯤 나오는가
5. 행운 주사위가 "아낄까 쓸까" 고민을 만드는가, 아니면 너무 강해서 긴장감을 없애는가 (보유 개수 조정)
5-1. 낮은 눈을 적에게 찍는 플레이가 실제로 쓰이는가
6. 환경 콤보가 실제로 자주 쓰이는가 (맵 3개 중 2개 이상에서)
7. 소문을 듣고 전설 장면을 노리는 플레이가 생기는가, 노리다가 지는 일이 너무 잦지 않은가
8. 라운드 사건이 "빨리 끝내야겠다"는 압박을 주는가, 사건을 막는 판단(그 적 먼저 잡기)이 실제로 나오는가
