# 아트 작업 개요

일러스트는 **Codex + 이미지 생성 모델(gpt-image 계열)**이 만들고, UI·이펙트·애니메이션은 **Claude가 코드로** 만든다.

| 파일 | 내용 |
|---|---|
| [AGENTS.md](AGENTS.md) | Codex 작업 지침 (작업 순서, 규칙, 보고 방식) |
| [style-guide.md](style-guide.md) | 프롬프트 블록, 에셋 종류별 크기, **대화 화면용 스탠딩 규칙**, 배경 제거, 품질 검사 |
| [characters.md](characters.md) | 캐릭터별 외형, **전투복·일상복**, 노출 등급, 프롬프트 |
| [manifest.csv](manifest.csv) | 만들어야 할 이미지 전체 목록 (336장). 수정은 `tools/art/gen_manifest.py`를 고친 뒤 `python tools/art/gen_manifest.py art/manifest.csv`로 다시 만든다 (진행 상태가 기록된 뒤에는 직접 수정) |
| [prompts/](prompts/) | 바로 붙여 넣을 수 있는 완성 프롬프트 (현재: 리나 수정본) |

## 제작 목록 요약 (총 336장)

| 종류 | 수량 | 구성 |
|---|---|---|
| 리나 수정본 (P0) | 2 | 전투복 수정본(화풍 기준), 일상복 첫 시안 |
| 캐릭터 레퍼런스 시트 | 19 | 동료 8명 × 전투복·일상복 + 과거 길드원 3명 |
| 동료 스탠딩 | 96 | 8명 × 의상 2벌 × 표정 6종 (기본, 웃음, 화남, 슬픔, 놀람, 당황) |
| NPC 스탠딩 | 15 | 주요 NPC 4명 × 표정 3종, 그 외 3명 × 1종 |
| **과거 길드원 스탠딩** | 12 | 에드릭, 알도, 젊은 고드릭, 모르칸트 × 표정 3종 (회상 전용) |
| 동료 SD (전투, 전투복) | 40 | 8명 × 동작 5종 (대기, 공격, 스킬, 피격, 쓰러짐) |
| **과거 길드원 SD** | 15 | 회상 파티 3명 × 동작 5종 |
| 적 SD | 60 | 일반 적 15종 × 3동작, 보스 3종 × 5동작 |
| 궁극기 컷인 | 8 | 동료 8명 × 1 |
| 스킬 아이콘 | 24 | 동료 8명 × 3 (스킬 2 + 궁극기) |
| 대화 배경 | 20 | 길드 하우스 4단계, 전성기 길드 하우스(회상), **봉인된 방 4곳**, 마을, 선술집, 숲, 수도원, 도시, 지역 지도 등 |
| 전투 맵 배경 | 9 | 챕터 3개 × 3맵 (마지막은 보스전) |
| 이벤트 CG | 7 | 챕터별 핵심 장면, 엔딩, 유료 동료 퀘스트 엔딩 2 |
| 호감도 CG | 6 | 무료 동료 6명 × 1 (유료 동료는 퀘스트 엔딩 CG가 겸함). 연애는 암시 정도 |
| 키 비주얼 | 1 | Steam·스토어 홍보 이미지의 원본 |
| 동료 팩 홍보 일러스트 | 2 | 유료 동료 2명 × 1. 인게임 상점과 Steam DLC 상점 이미지의 원본 |

> 전투 맵 배경은 SD 캐릭터와 시점을 맞추려고 "위에서 비스듬히 내려다보는 시점"(고전 JRPG식)으로 바꿨다.

> 이 중 표정 차분 96장(동료 80 + NPC 8 + 과거 길드원 8)은 새로 그리는 게 아니라 기본 표정에서 **얼굴만 편집**한다.
> 연대기 페이지, 여백 낙서, 회상의 세피아 효과는 코드로 만든다(Claude 담당). 이미지 생성 목록에 없다.

## 의상과 사용처

| 의상 | 쓰는 곳 | 노출 |
|---|---|---|
| 전투복 | 의뢰 수행 중 대화, 판정 대화, 전투 SD, 컷인 | 없음 (실용적인 중세 장비) |
| 일상복 | 길드 하우스, 캠프, 호감도 이벤트, 개인 스토리 일상 장면 | 캐릭터별 등급 (낮음/중간/높음) |

| 캐릭터 | 일상복 컨셉 | 노출 |
|---|---|---|
| 리나 | 요리에 실패 중인 앞치마 차림 | 낮음 |
| 세실 | 톰보이, 셔츠 묶어 입고 반바지 | 중간 |
| 아델하이트 | 밤샘 독서용 헐렁한 잠옷 | 낮음 |
| 미리엄 | 베일을 벗은 반전, 등 트인 원피스 | 높음 |
| 로웬 | 선술집 무대 의상 | 높음 |
| 고드릭 | 셔츠와 가죽 앞치마, 맥주잔 | 없음 |
| 이졸데 | 귀족 이브닝 드레스 | 높음 |
| 카샤 | 북방 자수 원피스, 화관 | 중간 |

## 단계

| 단계 | 수량 | 내용 |
|---|---|---|
| **P0 화풍 확정** | 2 | 리나 수정본 → 승인되면 화풍 기준 이미지로 고정 |
| **P1 체험판** | 168 | 동료 4명(리나, 세실, 아델하이트, 미리엄) 전체와 호감도 CG, 1장 적과 보스, 1장 배경·전투 맵, 1장 오프닝 CG, **과거 길드원 전체와 첫 회상(기록실)** |
| **P2 정식 출시** | 166 | 나머지 동료 4명, 2~3장 콘텐츠, 나머지 봉인된 방, CG, 키 비주얼, 동료 팩 홍보 일러스트 |

## 사람이 승인해야 하는 지점

1. P0 리나 전투복 수정본 → `art/refs/style-anchor.png`
2. 캐릭터·의상마다 레퍼런스 시트 승인 → 그 의상의 나머지 이미지 제작 시작
3. 각 이미지의 최종 승인 (`status=approved`)

## 아직 만들지 않는 것

- 유료 코스튬: 동료 팩이 확정된 뒤 캐릭터별로 스탠딩 6 + SD 5장 세트로 추가한다
- Steam 캡슐 이미지, 앱 아이콘, 로고: 정식 게임 제목이 정해진 뒤 키 비주얼에서 파생한다
