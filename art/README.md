| 파일 | 내용 |

## 사람이 승인해야 하는 지점

1. P0 스타일 시안 중 1장 선택 → `art/refs/style-anchor.png`
2. 캐릭터마다 레퍼런스 시트 승인 → 그 캐릭터의 나머지 이미지 제작 시작
3. 각 이미지의 최종 승인 (`status=approved`)

## 아직 만들지 않는 것

- 코스튬(유료 꾸미기): 동료 팩이 확정된 뒤 캐릭터별로 스탠딩 1 + SD 5장 세트로 추가한다
- Steam 캡슐 이미지, 앱 아이콘, 로고: 정식 게임 제목이 정해진 뒤 키 비주얼에서 파생한다
