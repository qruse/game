## 진행 방법

1. `art/AGENTS.md`의 작업 순서와 규칙을 따른다
2. 아래 **피드백** 칸을 먼저 읽는다. 재작업이면 피드백을 반드시 반영한다
3. `C01_portrait_combat_neutral`은 S01 승인본을 복사한 것이다. **새로 만들지 않는다**
4. `C01_portrait_combat_smile`은 기본 스탠딩의 **얼굴만 마스크 편집** (style-guide 3.1절)
5. SD 2장은 레퍼런스 시트를 참조해 만들고 배경을 제거한다 (style-guide 6절)
6. 끝나면 Claude가 **대화 화면·전투 화면 목업**에 얹어 확인한다

## 사용자 확인 포인트

- [ ] 웃음 표정으로 바꿨을 때 얼굴 밖(머리, 옷, 배경)이 그대로다 (겹쳐 보면 흔들림 없음)
- [ ] SD가 2.5등신이고 리나로 알아볼 수 있다
- [ ] SD 배경 제거가 깨끗하다
- [ ] 대화 목업에서 얼굴이 대사창에 가리지 않는다
- [ ] 전투 목업에서 SD 크기와 방향이 맞다
